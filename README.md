# 命格译码 / Mingecode

**状态：冻结 / Accepted（M0 文档基线）**

> 基于传统八字结构的东方现代人格解释系统：不是替你算命，而是重新翻译你。

## 当前阶段

仓库处于 **M0 仓库基线完成、M1 研究准备** 阶段。当前坚持 docs-first，只建立治理、研究与设计模板；仓库目前没有业务代码。M1 只允许研究候选维度、原型、规则、传统判词翻译、盲测、命名测试、排盘口径与边界敏感性，以及两个候选原型的轻量视觉简报；时间边界研究不等于实现排盘代码。

## 核心冻结决定

- MVP 不是传统算命、命运预测、心理诊断、改运消灾或付费批命服务。
- 当前唯一验证假设是：用户愿意认领、保存、分享结果，并邀请第二个人参与。
- 第一版偏正向、偏娱乐、轻量易懂，但必须保留温和且真实的失衡风险。
- 用户界面不展示未经验证的精确人格分数、百分比或数值雷达图。
- 性别可以选填，但不参与核心人格裁决、核心原型选择、特质排序或价值判断；只用于传统语境解释及必要称谓适配。
- 运行时采用确定性规则；大模型不得自由排盘、判断格局或裁决人格。
- MVP 不收集用户姓名；用户无需注册或登录即可获得完整核心结果。
- 分享、关注或提供联系方式均为自愿行为，不得作为解锁完整核心结果的条件。
- 原始出生日期、时间和地点默认不保存；能在客户端完成的计算优先在客户端完成。
- MVP 默认使用用户出生地对应的民用标准时间口径，版本标识为 `civil_time_v1`，暂不启用真太阳时。
- 子时换日、时辰与节气边界、夏令时、历史时区及模糊出生时间仍待 M1 研究，不得冒充已冻结规则。
- 所有人格、原型和规则在盲测通过前均为研究候选。
- M1 通过人工盲测前不得开始业务代码。

## 第一版结果范围

第一版结果只规划以下结构：

1. 一个核心人格 / 命格原型；
2. 2—3 个辅助特质；
3. 一句人格宣言；
4. 高光状态；
5. 翻车方式；
6. 别人最容易误解的地方；
7. 简短使用建议；
8. 文化研究与娱乐用途说明。

禁止流年灾祸、疾病预测、婚姻判决、贫富断言、宿命结论和“天选之人”式包装。

## 明确排除

当前阶段排除业务代码、Next.js 或其他应用工程、排盘库、规则引擎实现、数据库、API、Supabase、Vercel、部署、生产 CI、微信小程序、正式 Logo、完整高保真 UI 和全部人格卡。历史 source 中的 Next.js 方案属于**后续技术候选，当前禁止实施**。

## M1 准入条件

只有在 source 完整保留、文档与八份 ADR 齐备、品牌、性别、输入最小化和时间口径策略清晰、研究和设计模板建立、全部检查通过，且不存在业务代码、依赖、数据库、API、部署或 CI 时，才允许开始 M1 研究。进入 M1 不等于允许业务开发；只有纯内容盲测达到预设标准后，才可评估下一阶段。

## 用途声明

本项目仅用于文化研究与娱乐表达，不构成心理诊断、医疗建议、人生决策依据或命运预测。
