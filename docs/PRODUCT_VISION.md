# 产品愿景

**状态：冻结 / Accepted**

## 为什么不是传统算命

MVP 不预测未来，不裁定吉凶，不提供改运服务，也不把人生压缩成婚姻、财富、疾病或灾祸结论。传统八字结构是文化研究和解释素材，不是不可质疑的权威。

## 为什么是人格翻译

产品先把传统结构翻译为中性的行为机制，再表达这种机制的资源、代价和被误解方式。目标不是替用户定义命运，而是提供一种可检验、可拒绝、可认领的现代人格语言。

## “偏正向、偏娱乐”的含义

- 使用轻量、易懂、适合分享的语言。
- 优先呈现可行动的资源，不以恐吓制造依赖。
- 保留文化趣味，但不随意编造命理结论。
- 不声称心理测量学效度、科学评分或准确率。

## 为什么仍需真实阴影

每种行为机制都可能过度使用。结果必须包含温和但真实的失衡风险，不能把所有结构无条件洗白，不能把任何用户包装成“天选之人”。阴影需说明条件、边界和可能代价，而非人格羞辱。

## 第一版结果结构

1. 一个核心人格 / 命格原型；
2. 2—3 个辅助特质；
3. 一句人格宣言；
4. 高光状态；
5. 翻车方式；
6. 别人最容易误解的地方；
7. 简短使用建议；
8. 文化研究与娱乐用途说明。

用户界面不得展示未经验证的精确人格分数。强弱只使用“明显、偏强、适中、较少出现”等定性语言；第一版不显示百分比或数值雷达图。

## 用户认领与分享机制

结果先帮助用户判断“哪部分像我、哪部分不像我”，再提供保存和分享意愿入口，并观察是否愿意邀请第二个人。分享卡只保留最有辨识度的信息，不展示四柱、五行百分比、专业格局或吉凶结论。

## 明确禁止

- 恐吓、宿命论、婚姻判决、贫富断言、疾病和流年灾祸预测；
- 以“人人都是隐藏天才”替代真实区分；
- 用用户反馈临时迎合结果；
- 用大模型自由排盘、判断格局或裁决人格；
- 把内部权重包装成经验证的心理量表。

## 尚未验证的核心风险

- 候选维度和原型是否真正低重叠；
- 传统结构到现代行为机制的映射是否有证据且可反驳；
- 用户是否能在纯内容条件下识别本人报告；
- 正向语气是否造成巴纳姆效应；
- 用户是否真实愿意保存、分享和邀请第二人；
- 八字没一撇作为**候选 / Proposed / 待命名测试**的公开产品名是否被正确理解；
- 东方人格翻译器作为**候选 / Proposed / 待验证**的类别说明是否清晰。
