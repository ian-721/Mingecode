# 协作治理

**状态：冻结 / Accepted**

## 正式角色

### 赵焱阳

项目发起人、产品负责人、人格译码架构负责人。负责产品定位、MVP 边界、人格体系、命理规则、内容母本、技术推进和验证流程。

### 延雨婷

视觉与体验负责人、MVP 核心合作人。负责品牌视觉、命格卡视觉语言、结果体验、分享表达、UI 视觉和用户第一感受，并保留正式署名和贡献记录。

## 最终决策边界

| 范围 | 最终决策 |
|---|---|
| 产品、规则、内容准确性、技术与阶段推进 | 赵焱阳 |
| 视觉、版式、卡片系统与 UI 表现 | 延雨婷 |
| 是否公开上线 | 双方共同评审，赵焱阳承担最终产品责任 |

## 共同决策

双方共同确认原型命名、品牌气质、分享卡信息结构、对外首批视觉样稿和用户感受类争议。当前不自动将延雨婷定义为共同创始人，也不推断股权或收益关系。

## 用户测试裁决机制

1. 判断争议属于产品、规则、视觉还是用户感受；
2. 专业责任区由对应负责人决定；
3. 用户感受争议制作两个低成本 A/B 版本；
4. 预先记录问题、样本和通过标准；
5. 使用真实测试辅助裁决，如实保留反例，禁止虚构反馈。

## 每周评审

每周一次 45—60 分钟正式评审，只讨论：

1. 上周完成与证据；
2. 需要共同拍板的问题；
3. 本周唯一优先事项；
4. 进入“待研究”或停车场的想法；
5. 是否触发 ADR 或阶段停止条件。

异步看板建议使用“待研究、本周进行、等待对方、待评审、已冻结、暂不进入”状态。

## 设计交接模板

赵焱阳使用[候选原型视觉简报模板](../design/briefs/PERSONA_VISUAL_BRIEF_TEMPLATE.md)提供：定义、驱动力、高光、翻车、误解、建议、分享宣言和证据状态。延雨婷补充视觉关键词、避免元素、情绪、构图与可生产性。双方分别完成产品确认与视觉备注。

## 当前投入边界

- 只允许为两个候选原型准备轻量视觉简报和样稿；
- 纯内容盲测早于完整视觉系统；
- 不绘制全部人格卡，不制作正式 Logo 终稿或完整高保真 UI；
- 不因某个候选原型更好画而保留它。

## 商业化前复核

正式公开上线、收费、投资或商业合作、长期大量设计投入、商标或公司安排、全职参与发生前，双方另行形成书面合作与收益安排。私人关系不能替代正式项目治理、署名、贡献记录和决策边界。
