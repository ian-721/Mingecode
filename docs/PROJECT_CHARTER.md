# 项目章程

**状态：冻结 / Accepted**

## 项目起点

命格译码 / Mingecode 从一个判断出发：用户未必需要未来预测，而可能需要一套具有东方文化亲近感、能解释自身矛盾并可公开认领的人格语言。历史原始输入保留在 [`source/`](source/)；活跃决定以本章程与 ADR 为准。

## 用户真实需求

让用户以低门槛、现代语言理解传统八字结构可能映射出的行为机制，同时看见资源与代价，并决定是否愿意认领和分享。该需求仍需真实研究验证，不能视为市场事实。

## 产品目标

- 建立可追溯、可复现且性别中立的核心人格解释方法。
- 产出轻量、可理解、可保存和可分享的第一版结果结构。
- 保留匿名、无需登录即可获得完整核心结果的基础路径。
- 以明确记录的时间口径版本保证规则材料和测试结果可复现。
- 用纯内容盲测检验候选人格是否具备区分度。
- 用命名测试验证公开产品名候选，而非提前宣布品牌成立。

## 产品原则

- MVP 不收集用户姓名，原始出生日期、时间和地点默认不保存。
- 用户无需注册或登录即可获得完整核心结果；分享、关注和联系方式不得成为解锁条件。
- 性别可以作为可选解释层，但不参与核心人格裁决。
- 时间口径一致性是规则可复现、版本比较、错配报告和盲测有效性的前提。
- MVP 统一使用 `civil_time_v1`；不得在报告间静默切换时间口径。

## 非目标

不构建传统算命平台、命运预测、心理诊断、付费批命、改运消灾、完整命理体系、业务应用或生产基础设施；不输出流年灾祸、疾病、婚姻、贫富或宿命判决。

## 当前唯一验证假设

在不依靠恐吓、宿命、伪精确分数或精美视觉干扰的情况下，用户愿意认领、保存、分享更像自己的结果，并邀请第二个人参与。

## 成功标准

- 四选一纯内容盲测达到 M1 开始前预先记录的通过标准。
- 用户能说明选择理由，并表现出保存、分享或邀请第二人的真实意愿。
- 候选原型具有可区分性，且不依赖精英化、无脑吹捧或视觉包装。
- 研究过程如实记录反例、错配和未解决争议。

## 失败标准

- 多数用户无法区分本人报告与三份真实错配报告。
- 选择主要由统一的正向套话、原型名称或视觉包装驱动。
- 候选原型高度重叠，或只描述领导者、创业者和精英。
- 为追求传播而牺牲边界、隐私或真实阴影。

## 范围边界

M0 只建立仓库、文档、研究模板与治理基线。M1 只研究 4—6 个低重叠维度、6—8 个候选原型、30—50 条研究候选规则、传统判词翻译、四选一盲测、命名测试、排盘口径与边界敏感性，以及两个候选原型的轻量视觉简报。时间边界研究不等于实现排盘代码。

## 当前阶段门

M1 准入要求见 [M0 基线](M0_BASELINE.md)。纯内容盲测必须早于完整视觉制作；未达到预设通过标准不得进入下一阶段。历史 source 中提及的 Next.js 是**后续技术候选，当前禁止实施**。

## 停止条件

出现 source 缺失或变化、规则来源无法核验、虚构反馈、状态混写、隐私边界被突破、候选被冒充冻结、业务代码被提前引入或研究不能提供区分度证据时，停止推进并记录问题。
