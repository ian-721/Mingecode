# 《命格译码｜赵焱阳与延雨婷协作分工草案 v0.2》

**适用阶段：** M1 人格与规则验证 → M2 低保真原型  
**项目性质：** 赵焱阳个人独立产品，延雨婷作为核心视觉与体验合作人参与 MVP 共创  
**当前目标：** 先验证“用户是否愿意认领和分享”，暂不扩大为完整命理平台

---

## 一、先冻结本轮产品方向

### 1. 第一版的产品气质

第一版应当：

> **偏正向、偏娱乐、轻量易懂、有真实识别度。**

它不是专业命理报告，也不需要教育用户掌握十神、格局、旺衰和调候。

用户看到的应当是现代人格语言，例如：

> 你不是难合作，只是不愿意在合作中失去主体性。

而不是：

> 比劫旺而官杀弱，故主体意识较强。

命理结构只作为后台依据，前台主要负责让用户：

1. 看懂；
2. 认领；
3. 会心一笑；
4. 愿意截图；
5. 想发给朋友看。

### 2. 正向不等于无脑夸奖

每个结果保持：

> **七分认领感，三分真实阴影。**

结果可以让人舒服，但必须至少指出一种真实代价，否则很快会退化成“人人都是隐藏天才”的漂亮话。

推荐表达：

> 你的优势是敢于自我定标。  
> 但当这种力量过度使用时，你可能会把一切外部建议都误判成控制。

避免：

> 你天生独立，不受任何人束缚，是注定成大事的人。

### 3. 不展示精确分数

内部规则引擎可以继续使用数字权重，但用户界面不显示“78分”“92%”等虚假精度。

第一版只呈现：

- 核心命格原型；
- 2—3个辅助特质；
- 高光状态；
- 翻车状态；
- 最常见误解；
- 一句人格宣言。

需要表达强弱时，可使用：

> 明显、偏强、适中、较少出现。

第一版暂不做雷达图。

### 4. 性别采用“可选解释层”，不进入核心裁决层

这是目前最稳妥的折中方案。

用户可以选择：

- 男；
- 女；
- 其他／不愿说明；
- 跳过。

但性别**不得改变核心命格原型、特质排序和价值判断**。

它只用于两个位置：

#### 传统语境解释

例如：

> 在传统女命文本中，这种结构常被解释成“婚缘不足”；但这种说法把女性人生默认绑定在婚姻上。现代翻译更接近：你不容易以伴侣或外部权威作为人生坐标。

#### 文案称谓适配

必要时调整少量代词和历史背景，但不产生“男人这样是事业心，女人这样是婚姻问题”的双重标准。

因此，产品底层原则仍是：

> **同一种结构，先翻译成人的运行机制，再讨论古代如何按照性别误读它。**

# 二、双人角色定义

## 赵焱阳：产品与人格系统负责人

建议正式角色名称：

> **产品负责人 / 人格译码架构负责人**

你负责决定产品“到底是什么、为什么成立、怎样被验证”。

### 主要责任

| 领域 | 具体责任 |
|---|---|
| 产品方向 | 定位、MVP边界、用户路径、优先级与阶段门 |
| 人格系统 | 原型、特质、规则、冲突裁决与结果可追溯性 |
| 内容母本 | 核心定义、高光、阴影、误解、成长建议与分享文案 |
| 技术实现 | PRD、数据结构、规则引擎、前后端与部署推进 |
| 用户研究 | 盲测设计、种子用户组织、反馈分析与迭代结论 |
| 增长实验 | 《古人误会你了》选题、渠道试验与传播数据 |
| 项目管理 | 任务拆解、版本冻结、范围控制与上线决策 |

你的最终拍板范围：

- 产品是否做；
- 功能是否进入 MVP；
- 某条规则是否达到上线标准；
- 人格体系是否具备足够区分度；
- 技术和项目节奏；
- 是否进入下一阶段。

---

## 延雨婷：品牌视觉与体验表达负责人

建议正式角色名称：

> **视觉与体验负责人**

不建议只叫“美术”，因为她负责的不只是画几张插图，而是：

> **决定用户第一眼如何理解、感受和分享这个产品。**

### 主要责任

| 领域 | 具体责任 |
|---|---|
| 品牌视觉 | Logo方向、色彩、字体、版式与整体视觉气质 |
| 命格卡系统 | 卡面结构、插画语言、符号体系与系列一致性 |
| 结果体验 | 结果页信息层级、视觉节奏、情绪感受与截图区域 |
| 分享传播 | 小红书图卡、分享海报、封面模板与社交媒体素材 |
| UI设计 | 首页、输入页、结果页、反馈页的视觉与交互表现 |
| 视觉规范 | 组件、间距、字号、图标、插图和导出规格 |
| 视觉测试 | 判断作品是否想点、想看、想保存、想分享 |

她的最终拍板范围：

- 视觉风格是否成立；
- 页面信息如何排布；
- 卡片是否具有系列感；
- 插画、字体和颜色如何组合；
- 哪种视觉表达最适合用户截图传播。

---

# 三、共同决策范围

以下事项必须共同确认：

1. 核心命格原型名称；
2. 每张卡的象征物和视觉隐喻；
3. 品牌总体气质；
4. 结果页最醒目的那一句话；
5. 分享卡上保留哪些信息；
6. 对外发布的首批内容；
7. 最终面向用户的样稿是否“像命格译码”。

原因很简单：

> 原型名字既是规则输出，也是视觉角色；分享文案既是内容，也是画面中心。

任何一方单独决定，都可能出现内容与视觉脱节。

---

# 四、决策权边界

建议采用下面的规则，避免每个问题都无限讨论。

| 事项 | 主要负责人 | 最终决定 |
|---|---|---|
| 项目定位和产品边界 | 赵焱阳 | 赵焱阳 |
| 命理规则和人格裁决 | 赵焱阳 | 赵焱阳 |
| 内容准确性和风险边界 | 赵焱阳 | 赵焱阳 |
| 视觉语言和卡片设计 | 延雨婷 | 延雨婷 |
| UI视觉与版式 | 延雨婷 | 延雨婷 |
| 技术实现方式 | 赵焱阳 | 赵焱阳 |
| 原型命名 | 共同 | 用户测试辅助裁决 |
| 品牌气质 | 共同 | 共同确认 |
| 分享卡最终版本 | 共同 | 真实用户反馈裁决 |
| 是否公开上线 | 共同评审 | 赵焱阳承担最终产品责任 |

遇到意见分歧时，不使用“谁更会说”决定，按以下顺序处理：

1. 先确认争议属于产品、规则还是视觉；
2. 属于某一专业责任区，由对应负责人决定；
3. 属于用户感受问题，制作两个低成本版本；
4. 找5—10名目标用户做无提示选择；
5. 用结果决策，不靠情侣内部反复争论。

# 五、最重要的协作顺序

## 不要现在就让她画完全部命格卡

目前人格原型和规则尚未通过盲测。此时直接设计八张、十二张完整卡片，会出现两个问题：

1. 原型后续合并或删除，美术投入被浪费；
2. 好看的视觉会干扰盲测，让用户因为卡面而不是人格内容选择结果。

因此正确顺序是：

> **先证明人格有区别，再把区别画出来。**

---

## M1-A：人格候选与视觉概念阶段

### 你负责交付

- 4—6个候选人格维度；
- 6—8个候选命格原型；
- 每个原型的一页内容简报；
- 30—50条初始规则；
- 统一长度的结果文案；
- 用户盲测材料。

### 她负责交付

此阶段只做轻量探索：

- 2—3套视觉方向 Moodboard；
- 两个差异明显的命格卡样稿；
- 一套基础卡片网格；
- 一个结果页视觉概念稿；
- 对原型命名和象征物提出反馈。

### 阶段限制

不得：

- 画完所有人格卡；
- 制作完整设计系统；
- 打磨大量动效；
- 进入正式品牌重设计；
- 因为某个原型“好画”就保留它。

---

## M1-B：纯内容盲测阶段

这一阶段尽量淡化视觉影响。

测试材料采用：

- 相同字体；
- 相同长度；
- 相同版式；
- 不出现原型名称；
- 不出现插画；
- 不出现传统命理术语。

验证核心只有一个：

> 用户能否从四份同质量结果中识别出更像自己的一份。

她可以参与观察测试，但不应通过美术包装提高某份结果的吸引力。

只有盲测达到最低标准，才进入正式视觉制作。

---

## M2：低保真产品与完整视觉系统阶段

盲测通过后，她再正式展开：

- 品牌视觉基础；
- 完整卡片母版；
- 6个左右正式命格卡；
- 首页视觉；
- 输入页；
- 结果页；
- 分享页；
- 移动端适配；
- 社交媒体内容模板。

这样她投入的每一份创作，都会建立在已经通过初步验证的人格体系上。

---

# 六、人格内容简报交接模板

你不能只对她说：

> “这个人格是开疆型，你自由发挥。”

每个命格必须先给一份统一简报，否则视觉容易只剩玄学符号。

推荐模板：

```markdown
# 命格视觉简报

## 暂定名称
开疆试验者

## 一句话定义
看到没有路的地方，会本能地想先走出一条路。

## 核心驱动力
探索、启动、重新定义问题。

## 高光状态
敢于进入未知领域，能从零建立雏形。

## 翻车状态
启动过多，缺少收口；把新鲜感误当成价值。

## 别人最容易误解的地方
别人以为他不稳定，其实他在寻找真正值得长期投入的方向。

## 视觉关键词
破土、第一束光、地图边界、未完成的道路。

## 避免元素
征服者、帝王、绝对强者、天选之子。

## 情绪感觉
有生命力、有未知感，但不是攻击性和权力感。

## 分享文案
我不是总想换方向，我只是不愿在一条错误的路上证明坚持。
```

她可以在这个基础上决定：

- 人物或非人物；
- 抽象或具象；
- 颜色；
- 构图；
- 象征物；
- 卡片气质。

---

# 七、视觉方向的边界

第一版最好避免传统算命产品常见的视觉套路：

- 满屏金色；
- 八卦、铜钱和龙纹堆叠；
- 神秘黑紫色宇宙背景；
- 古风算命摊；
- “大师批命”式权威感；
- AI生成的千篇一律国潮仙人。

推荐目标是：

> **东方文化底色＋现代人格卡＋适合年轻人分享的编辑设计。**

她可以先探索三个方向：

### 方向A：现代东方编辑风

留白、汉字、现代排版、少量传统纹理，适合小红书和内容传播。

### 方向B：人格收藏卡风

每个命格拥有独立象征物、编号和卡面，增强认领和收藏欲。

### 方向C：轻角色插画风

每种人格拥有一个现代化角色或精灵形象，更亲切、娱乐性更强。

首轮不急着选终局风格，先各做一张低成本样稿，让真实目标用户选择。

---

# 八、第一版命格卡信息结构

建议分享卡只保留六层信息：

```text
命格译码

「原型名称」

一句人格宣言

你的高光：
一句话

你的翻车：
一句话

别人最容易误解你的地方：
一句话

不是替你算命，而是重新翻译你
```

不要在分享卡塞入：

- 四柱；
- 五行百分比；
- 十神表；
- 专业格局；
- 大段解释；
- 精确评分；
- 吉凶预测。

详细解释留在结果页，分享卡只负责：

> **让我认领，让朋友看懂，让人产生点击欲。**

---

# 九、协作节奏

不建议把你们日常所有聊天都变成项目会议。

采用一个轻量节奏即可。

## 每周一次正式评审

时长控制在45—60分钟，固定讨论：

1. 上周完成了什么；
2. 哪些问题需要共同拍板；
3. 本周唯一优先事项；
4. 哪些想法进入停车场，而不是立即执行。

## 平时异步协作

使用一个共同看板，建议栏目：

- 待研究；
- 本周进行；
- 等待对方；
- 待评审；
- 已冻结；
- 暂不进入。

所有新想法先进入“待研究”，不得因为聊天时突然兴奋就自动插入当前工作。

## 反馈规则

对设计或文案反馈，不说：

> 感觉不对。  
> 好像不够高级。  
> 我不太喜欢。

统一说清楚：

> 哪个用户目标没有实现？  
> 哪条信息没有被看见？  
> 它与哪个已冻结方向冲突？  
> 需要保留什么，改变什么？

# 十一、验收标准

她的设计不是以“画得漂亮”为唯一标准，而是必须满足：

### 识别度

不同命格卡遮住名称后，仍能感受到气质差异。

### 系列感

所有卡属于同一个品牌，不能像从不同素材库拼出来。

### 可读性

手机屏幕上三秒内能看见：

- 我是什么；
- 哪句话最像我；
- 为什么值得分享。

### 分享欲

用户愿意把它放到朋友圈、小红书或发给朋友，而不是觉得像算命广告。

### 可扩展性

未来新增命格时，可以沿用相同网格和视觉逻辑，不需要每次重做整个系统。

### 生产可行性

图像、字体和组件能够在网页、海报和内容平台中稳定复用。

# 十二、项目与贡献归属

这一部分最好现在温柔地说清楚，而不是等赚钱以后再猜。

## MVP试作阶段的默认安排

- 命格译码继续作为赵焱阳的个人独立项目；
- 延雨婷以“视觉与体验负责人、核心合作人”身份参与；
- 暂不因为参与试作自动定义为共同创始人；
- 双方贡献通过任务记录、设计源文件和版本记录保留；
- 她拥有明确署名权和作品集展示权；
- 项目获得对已采用视觉资产的持续产品使用权。

## 商业化前必须重新确认

在发生以下任一情况前，双方应单独讨论并形成简短书面约定：

- 正式公开上线；
- 开始收费；
- 收到投资或商业合作；
- 需要大量持续设计投入；
- 计划注册商标或公司；
- 一方准备成为长期全职参与者。

届时可以选择：

1. 有偿设计合作；
2. 产品收入分成；
3. 长期核心合作者；
4. 共同项目或共同创始安排。

现阶段不需要急着分股权，但不能默认：

> “因为是情侣，所以以后自然都算共同的。”

把规则说清楚，反而更能保护关系和创作热情。

# 十三、第一轮两周行动安排

## 第1周：内容与风格探索

### 你

- 从候选中压缩出6个命格原型；
- 为其中两个写完整视觉简报；
- 冻结第一版结果卡的信息结构；
- 准备不带视觉的盲测文案。

### 她

- 根据两个视觉简报制作3套Moodboard；
- 从中选择两个方向各做一张卡片样稿；
- 不追求完整，只验证气质与分享感。

### 共同

找5—10名朋友只看卡片，不解释背景，询问：

- 第一眼觉得它是什么产品？
- 哪张更想点进去？
- 哪张更愿意发出来？
- 是否感觉像传统算命广告？
- 最先注意到哪句话？

---

## 第2周：结果页与第一次收束
