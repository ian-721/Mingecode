# M1 研究计划

**状态：候选研究计划 / Proposed / 待验证**

## M1 唯一范围

1. 研究 4—6 个低重叠人格维度；
2. 研究 6—8 个候选原型；
3. 建立 30—50 条研究候选规则；
4. 研究传统判词与现代行为机制的映射；
5. 为每位被试准备本人规则报告与三份真实错配报告；
6. 执行四选一纯内容盲测；
7. 对公开产品名候选进行基础命名测试；
8. 为两个候选原型准备视觉简报；
9. 由延雨婷探索三套轻量 Moodboard：现代东方编辑风、人格收藏卡风、轻角色插画风。

## 研究原则

- 所有维度、原型和规则在通过盲测前均为研究候选；
- 不虚构规则、来源、命理共识、用户反馈或测试结果；
- 不因视觉好看或容易绘制而保留无区分度原型；
- 每个原型同时包含资源与代价，不设置人格高低等级；
- 传统材料必须记录历史语境、性别偏见、支持与反向证据；
- 内部可保留连续权重，但不得包装成心理测量学量表；
- 性别不参与核心人格原型裁决或特质排序。

## 顺序

1. 定义候选维度和重叠判据；
2. 整理候选原型、来源与反例；
3. 建立规则来源登记和争议日志；
4. 生成等长、同语气、正负比例受控的报告；
5. 预先记录盲测通过标准；
6. 先执行纯内容盲测；
7. 根据区分度淘汰或合并候选；
8. 再执行轻量命名和视觉探索。

纯内容盲测必须早于完整视觉制作。只有盲测达到预设标准，才允许提出下一阶段 ADR。

## 明确禁止

- 不进入业务代码、Next.js、数据库、API、依赖、部署或 CI；
- 不虚构 30—50 条规则或 6—8 个已确认原型；
- 不制作全部人格卡、正式 Logo 或完整高保真 UI；
- 不将候选写成正式人格体系或已验证规则；
- 不使用精确用户分数、科学评分或准确率宣传；
- 不把“偏娱乐”当作随意编造结论的许可。

## 研究交付

- 候选维度表与重叠说明；
- 候选原型材料与淘汰记录；
- 规则来源登记、争议日志和版本状态；
- 四选一盲测材料与真实记录；
- 命名测试材料与真实记录；
- 两个候选原型的视觉简报；
- 三套轻量 Moodboard 方向说明；
- 阶段复盘与是否进入下一阶段的证据。
