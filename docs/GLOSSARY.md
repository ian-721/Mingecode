# 术语表

**状态：冻结 / Accepted**

| 术语 | 定义与状态 |
|---|---|
| 命格译码 | 冻结的内部中文项目与规则工程名；以现代语言翻译传统八字结构，不等同公开品牌。 |
| Mingecode | 冻结的内部英文工程名。 |
| 八字没一撇 | 候选 / Proposed / 待命名测试的公开产品名首选，尚未最终冻结。 |
| 古人误会你了 | 冻结的传播内容栏目。 |
| 东方人格翻译器 | 候选 / Proposed / 待验证的产品类别说明。 |
| 核心原型 | 对主要行为机制的研究候选归纳；盲测前不是正式人格分类。 |
| 辅助特质 | 用于补充核心原型的 2—3 个研究候选特征。 |
| 高光 | 某种行为机制在适配情境中的资源性表现。 |
| 翻车 | 同一机制过度使用、情境不适配或失衡时的真实代价。 |
| 研究候选 | 尚未通过盲测，不得作为正式规则、人格或产品结论。 |
| 确定性规则 | 同一输入与同一规则版本产生可复现结果的规则运行方式。 |
| 四选一盲测 | 隐藏原型名和视觉影响，让用户在本人报告与三份真实错配报告中排序的纯内容测试。 |
| 传统性别语境 | 古代文本按性别赋予不同评价的历史背景；可解释，但不得进入核心人格裁决。 |
| 公开产品名 | 面向用户传播的产品名称层，可在测试失败后更新而不改动工程身份。 |
| 内部工程名 | 稳定承载仓库、规则、技术文档和项目识别的名称层。 |
| 冻结 / Accepted | 已批准且当前阶段必须遵守；改变时必须新增 ADR。 |
| 候选 / Proposed | 当前优先方案，仍需测试或人工确认。 |
| 待核验 / Pending Verification | 需要查证、交叉验证或现实测试的陈述。 |
| 排除 / Excluded | 明确不进入当前 MVP 或当前阶段的事项。 |
