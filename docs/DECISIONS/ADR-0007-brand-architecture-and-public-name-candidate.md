# ADR-0007：品牌分层与公开产品名候选

**状态：候选 / Proposed / 待命名测试**

- **Title:** 品牌分层与公开产品名候选
- **Status:** Proposed
- **Date:** 2026-07-27

## Context

历史 M0 将“命格译码 / Mingecode”同时作为产品与工程身份。当前需要让稳定的规则工程身份与可通过用户测试调整的公开品牌层分离，同时避免把内容栏目混写为产品名。

## Decision

- 保留命格译码 / Mingecode 作为内部项目、规则工程和仓库名称；
- 将八字没一撇列为**候选 / Proposed / 待命名测试**的公开产品名首选；
- 古人误会你了作为冻结的内容栏目；
- 东方人格翻译器作为**候选 / Proposed / 待验证**的类别说明；
- 一撇是命，一捺是你作为**候选 / Proposed / 待验证**的副口号；
- 当前不宣布公开产品名最终冻结；
- 正式品牌视觉和公开上线前完成基础命名测试；
- 候选名失败时只更新公开品牌层，不改变规则工程身份。

## Consequences

- 仓库、规则标识与技术资产保持稳定。
- 对外名称和副口号可以基于证据迭代。
- 命名测试前只允许轻量 Moodboard，不制作正式 Logo 终稿或完整品牌系统。
- 活跃文档必须持续标明候选状态。

## Supersedes / Superseded by

- **Supersedes:** 旧 M0 中将“命格译码”同时冻结为公开产品名与内部工程名的单层品牌决定。
- **Superseded by:** 无。

## Open questions

- 候选名是否让用户正确理解产品与八字的关系？
- 是否产生“产品还没做完”或传统算命广告的误读？
- 类别说明与副口号是否提升理解，还是增加信息负担？
