# ADR-0006：协作角色与决策边界

**状态：冻结 / Accepted**

- **Title:** 赵焱阳与延雨婷的协作角色、决策权和边界
- **Status:** Accepted
- **Date:** 2026-07-27

## Context

内容规则与视觉体验高度相互影响，但双方需要清晰责任、署名与冲突处理机制，避免以私人关系替代项目治理，也避免在验证前投入完整视觉系统。

## Decision

赵焱阳是项目发起人、产品负责人和人格译码架构负责人，对产品、规则、内容准确性、技术与验证流程最终决策。延雨婷是视觉与体验负责人、MVP 核心合作人，对视觉、版式、卡片系统与 UI 表现最终决策。

原型命名、品牌气质、分享卡信息结构、首批视觉样稿和用户感受争议共同决策；用户感受争议优先制作低成本 A/B 版本，用真实测试辅助裁决。当前只允许两个候选原型的视觉简报和样稿。商业化、收费或长期大规模投入前，双方另行确认合作与收益安排；当前不自动定义共同创始人关系。

## Consequences

- 延雨婷保留正式署名与贡献记录。
- 专业边界清晰，跨域争议有测试路径。
- 不绘制全部人格卡，不以视觉投入锁定研究候选。

## Supersedes / Superseded by

- **Supersedes:** 任何以私人关系称谓替代正式角色和治理的非正式表达。
- **Superseded by:** 无。

## Open questions

- 商业化前采用何种书面合作安排？
- 作品集展示和已采用视觉资产使用范围需在正式制作前细化。
