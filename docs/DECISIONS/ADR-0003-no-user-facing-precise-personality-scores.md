# ADR-0003：不展示未经验证的精确人格分数

**状态：冻结 / Accepted**

- **Title:** 不向用户展示未经验证的精确人格分数
- **Status:** Accepted
- **Date:** 2026-07-27

## Context

内部研究可能需要连续权重，但目前没有心理测量学验证。向用户展示“78 分”“92%”或精确雷达数值会制造不存在的精度与科学权威。

## Decision

用户界面不得展示未经验证的精确人格分数、百分比或第一版数值雷达图。强弱只使用“明显、偏强、适中、较少出现”等定性语言。内部连续权重可以保留，但不得包装成经验证的量表，也不得在验证前宣传“准确率”或“科学评分”。

## Consequences

- 结果表达需优先解释机制、情境、资源和代价。
- 研究记录必须区分内部计算权重与对外结论。
- 未来任何精确分数展示都需要方法验证和新 ADR。

## Supersedes / Superseded by

- **Supersedes:** 无。
- **Superseded by:** 无。
