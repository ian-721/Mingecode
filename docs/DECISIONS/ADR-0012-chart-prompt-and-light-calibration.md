# ADR-0012｜命盘起题 + 轻问答校准

**状态：Accepted**  
**日期：2026-07-30**  
**授权人：赵焱阳**

## 背景

M1-BR-R1 复核确认，当前排盘事实和研究证据不能唯一计算关键输出过滤、替代出口、财解、扶身、官杀主次、负荷、竞争、`capacity` 或人为不确定度计数。继续让命盘独立产生 `supported / candidate / closed`，会把研究假设伪装为确定事实。

项目目标仍是轻松、有趣、略准、可分享的小工具，不是自动格局裁决器。继续扩大对象级命理研究不是完成 H5 Demo 的最小充分路径。

## 决定

### 1. 命盘只负责起题

命盘只提取五类十神家族的稳定存在性与可见性：

```text
input / output / peer / authority / completion
```

这些 cue 只用于排列四条提问路线的先后，不参与现实路线计分，不提高门槛，也不覆盖用户回答。

### 2. 四签名降为题库路由键

`SIG-A1 / SIG-A2 / SIG-B1 / SIG-C1` 继续作为十二个已批准题槽的内部路由键和文化解释假设，不再表示命盘确认的人格签名。

旧 `SignatureLevel`、`SignatureAssessment`、`SignatureCandidate`、`capacity`、`uncertaintyCount` 与证据簇计数退出运行合同，不得改名保留。

### 3. 回答独立裁决现实路线

- 默认四题；
- 仅在并列、低支持、较多不确定或 mixed 候选仍未分开时增加第五、六题；
- 六题后必须结束；
- 每个明确选择只给对应路线 `+1`；
- `uncertain` 和命盘 cue 均为 `+0`；
- 不使用负分、权重、百分比或人格分数。

四种关系状态继续保留，但含义改为：

```text
aligned     起题主题与现实主路线同向
adapted     现实主路线不同于起题主题
mixed       两条路线在不同情境成立且直接比较为 1:1
unresolved  六题后仍无唯一主路线或不确定回答过多
```

### 4. 未知时柱不制造缺失

未知时柱时只使用年、月、日已观察到的正向 cue。未观察到的 family 标记为 `unknown`，不得标记为 `not_observed`，不得生成或保存虚构时柱。

多候选盘只用跨盘一致的 cue 排题。时间稳定性在 cue 聚合后判断；多个时间 instant 本身不等于 `boundary_sensitive`。

### 5. 授权边界

本 ADR 在 ADR-0011 已批准的非生产 H5 Demo 边界内，授权用 R2 混合模型替换旧签名确定性实现，并更新必要类型、接线、直接耦合的临时文案和测试。

继续禁止：

- 改变页面结构、视觉系统、依赖、排盘库或 `civil_time_v1`；
- 新增题槽、路线、人格维度、传统命理体系、外部服务或持久化；
- 部署、转 Ready 或合并 PR #5；
- 把 cue、答案、内部路线、计分或出生资料写入分享、URL、日志或存储；
- 宣称命盘预测正确、用户改变命运或真人效度已经验证。

## 替代关系

本 ADR 替代 ADR-0009 中“命盘最多提出三个结构签名候选、默认三题最多四题”的运行模型。ADR-0009 作为历史研究决定保留，不回写。

ADR-0011 的非生产、隐私、确定性运行时、Draft PR 和不部署边界继续有效。

实施合同为：

`research/m1br/v0.3/HYBRID_CANDIDATE_MODEL_CONTRACT_v0.4.md`

原 `BACKSTAGE_SIGNATURE_IMPLEMENTATION_CONTRACT_v0.1.md` 的签名三态部分退役，不得作为实现依据。

## 回滚与停止条件

本轮应形成一个可回退 commit。回滚可以撤销该 commit，但不得恢复旧三态签名为产品结果。

出现以下任一项立即停止：

- 需要超过六题；
- 需要命盘给回答加权；
- 需要第十三个题槽或第五条路线；
- 需要心理量表、大模型、外部服务、持久化、依赖、部署或页面结构变化；
- 需要重新发明 `capacity`、负荷、竞争或官杀主次算法。
