# ADR-0009｜命盘候选 + 最少校准题的混合译码模型

**状态：Accepted（仅研究方向）**  
**日期：2026-07-30**

## 背景

M1-A 与后续规则审查证明：将八字结构拆成大量原子规则，再由这些规则直接裁决现代人格，容易同时出现三类问题：

1. 同一结构事实被重复解释；
2. 为提高区分度而过度推断现代行为；
3. 为避免过度推断又把结果压缩成少量工作流程描述。

原六维、八原型和四十条候选规则因此不进入正式人格冻结。Draft PR #3 保留为该方法路线的研究记录，不作为即将上线的正式规则库。

项目仍然是一个轻量工具。前台流程不得退化成长问卷或心理量表。

## 决定

### 1. 命盘不直接给出最终人格

命盘只生成最多三个**结构签名候选**。候选表示某种运行路线在盘面中值得进一步询问，不表示已经确认用户现实中的行为。

### 2. 使用最少校准题消除近邻歧义

- 默认三题；
- 只有答案冲突或并列时增加第四题；
- 总题库暂定十二个题槽；
- 每道题只区分两个已由命盘提出的近邻候选；
- 不向所有用户展示同一套长题库。

### 3. 题目只询问可观察行为

题目不得询问抽象自我评价，例如“你是否理性”“你是否有边界感”。题目必须围绕具体场景、处理顺序、行动终点或明确反例。

### 4. 回答不静默覆盖命盘

最终结果保留两层：

```text
命盘底色：结构候选
现实校准：用户在现实中更常采用的路线
```

二者关系只允许四种状态：

```text
aligned       结构候选与现实路线一致
adapted       命盘候选存在，但现实中长期采用另一条策略
mixed         两条路线在不同情境中分别成立
unresolved    现有信息不足，不强行定稿
```

### 5. 当前核心对象是结构签名，不是人格类型

M1-BR 暂时保留四个候选结构签名：

```text
SIG-A1  输入条件 → 第一版
SIG-A2  成形判断 → 公开输出
SIG-B1  权限/标准 → 可执行边界
SIG-C1  输出对象 → 完成/后续承诺
```

它们只是研究候选。容量、显隐、负荷、冲突、时间边界只作修饰或守门。

### 6. 前台文案暂不冻结

现有示例、报告标题和第二人称表达均不视为获批文案。M1-BR 只冻结数据结构、决策逻辑、题槽和测试方法。

前台文案必须在后续单独完成自然语言编辑，不得直接复用本阶段的结构说明。

### 7. 继续遵守既有约束

- 运行时保持确定性，不由大模型裁决；
- 不展示精确人格分数；
- 性别不进入核心裁决；
- 原始出生资料默认不保存；
- `civil_time_v1` 继续有效；
- 本 ADR 不授权业务代码、真人测试或完整视觉系统。

## 影响

### 正面

- 保留八字作为东方文化入口；
- 将无法仅靠命盘确认的部分交给极少量现实行为问题；
- 避免将产品做成长测试；
- 可以把命盘与现实策略之间的差异作为结果内容，而不是当作错误隐藏。

### 代价

- 结果不再宣称由八字单独推出；
- 需要维护小型题库和自适应选择逻辑；
- 题目质量会直接影响结果，需要单独测试；
- 旧六维、八原型和二十四槽不再是产品结构约束。

## 不做

- 不建立十六型或更多组合类型；
- 不引入长问卷；
- 不用题目生成心理量表分数；
- 不新增传统命理体系来补齐候选数量；
- 不在本阶段撰写正式结果文案；
- 不执行真人测试。
