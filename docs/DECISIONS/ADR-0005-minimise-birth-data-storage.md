# ADR-0005：最小化出生资料处理

**状态：冻结 / Accepted**

- **Title:** 最小化出生资料处理并默认不保存原始输入
- **Status:** Accepted
- **Date:** 2026-07-27

## Context

姓名、出生日期、时间和地点都可能增加识别与隐私风险。当前验证目标不要求建立长期用户档案、登录门槛或保存原始出生输入。完整核心结果应当可以在匿名路径中获得。

## Decision

- MVP 不收集用户姓名。
- 性别继续遵循 [ADR-0002](ADR-0002-gender-as-optional-explanation-layer.md)：可以选填，但不参与核心人格裁决。
- 用户无需注册或登录即可获得完整核心结果。
- 不得把登录、关注、分享或提供联系方式作为解锁完整核心结果的条件。
- 原始出生日期、时间和地点默认不保存；能在客户端完成的计算优先在客户端完成。
- 研究记录使用匿名编号，避免复制原始出生资料。
- 后续如需账户、同步或跨设备保存，必须由新 ADR 批准；除非重新获得明确产品授权，不得改变匿名使用的基础路径。
- 任何新增收集、传输、日志或持久化需求都必须证明最小必要性、定义保留期与删除机制，并由新 ADR 批准。

## Consequences

- 当前不创建数据库、API、Supabase 或分析管道。
- 当前不创建登录系统，也不设计账户功能。
- “无需登录”不等于永远禁止未来的可选账户；它冻结的是完整核心结果的匿名基础路径。
- 后续工程必须把数据最小化作为设计输入，而不是上线后补救。

- **Superseded by:** 无。

## Open questions

- 后续是否需要完全离线或客户端排盘，待技术阶段核验。
