# ADR-0005：最小化出生资料处理

**状态：冻结 / Accepted**

- **Title:** 最小化出生资料处理并默认不保存原始输入
- **Status:** Accepted
- **Date:** 2026-07-27

## Context

出生日期、时间和地点具有个人识别与隐私风险。当前验证目标不要求建立长期用户档案或保存原始出生输入。

## Decision

原始出生日期、时间和地点默认不保存。能在客户端完成的计算优先在客户端完成。任何新增收集、传输、日志或持久化需求都必须证明最小必要性、定义保留期与删除机制，并由新 ADR 批准。

## Consequences

- 当前不创建数据库、API、Supabase 或分析管道。
- 研究记录使用匿名编号，避免复制原始出生资料。
- 后续工程必须把数据最小化作为设计输入，而不是上线后补救。
