# ADR-0014：独立维护与实际贡献署名

**状态：Accepted**  
**决定日期：2026-10-24**  
**决策人：赵焱阳（项目 Owner）**

## 背景

原计划的双人协作分工未形成实际的共同交付。当前仍保留拟议角色、贡献署名和共同审批条件，会错误描述项目的真实维护与责任状态。

## 决定

- 当前命格译码由赵焱阳独立负责产品、设计方向、实现与最终决策。
- `CONTRIBUTORS.md` 只记录已确认的实际贡献，不将未执行的计划分工当作已完成贡献。
- 取消基于未实施协作而设定的双人审批条件。后续如有实际贡献者，再按真实交付和明确授权确定相应的署名或责任。
- 撤除当前版本中不再适用的协作治理说明、原分工草案和 ADR-0006。它们仍可通过 Git 历史追溯，不改写历史提交。

## 影响边界

本决定取代原 ADR-0006 的当前效力，并仅替代 ADR-0010 中涉及双人文案/视觉批准的要求。其他已冻结的产品语义、用户隐私、确定性规则、内容质量要求与测试边界继续有效。

此变更不表示产品已通过用户验证、已合并或已获公开发布授权。
