# ADR-0004：确定性运行时，不由大模型裁决

**状态：冻结 / Accepted**

- **Title:** 确定性运行时，不由大模型承担人格裁决
- **Status:** Accepted
- **Date:** 2026-07-27

## Context

规则结果需要可复现、可追溯和可审查。大模型自由排盘、判断格局、选择人格或根据反馈迎合用户，会破坏一致性并掩盖规则缺陷。

## Decision

未来运行时采用确定性规则：同一输入与同一规则版本应产生可复现结果。大模型不得自由排盘、判断格局、决定核心原型、调整特质排序或根据用户反馈临时迎合结果。未来仅可在结论已经确定后辅助语言表达，且输出必须经过审核。

## Consequences

- 规则、冲突、版本与证据必须可追溯。
- 语言层不得改变裁决层结论。
- M1 只研究规则，不实现运行时。

## Supersedes / Superseded by

- **Supersedes:** 无。
- **Superseded by:** 无。
