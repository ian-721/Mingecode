# ADR-0002：性别作为可选解释层

**状态：冻结 / Accepted**

- **Title:** 性别作为可选解释层，不进入人格裁决
- **Status:** Accepted
- **Date:** 2026-07-27

## Context

旧 M0 决定“MVP 不收集性别”，目的是避免传统命理中的性别双重标准。后续协作草案指出，如果完全移除性别，产品也可能失去解释和批判传统文本历史性别语境的能力。

## Decision

性别可以作为可选输入，支持“男、女、其他 / 不愿说明、跳过”。性别不参与核心人格裁决，不得改变核心人格原型、特质排序或同一结构的价值高低，只能用于：

1. 解释传统命理文本中的历史性别语境；
2. 必要的称谓和代词适配。

同一结构必须先翻译成中性的行为机制，再解释古代为何按性别赋予不同评价。不得重建“男命看事业、女命看婚姻”的双重标准。

## Consequences

- 核心人格引擎保持性别中立。
- 研究材料需标记传统来源中的性别偏见。
- 跳过性别不影响核心结果完整性。
- 文案和测试必须验证解释层是否引入新的刻板印象。

## Supersedes / Superseded by

- **Supersedes:** 旧 M0 中的“MVP不收集性别”决定。
- **Superseded by:** 无。

## Open questions

- 哪些历史语境确有解释价值，哪些应直接排除？
- 代词适配是否真的必要，需由可用性测试确认。
