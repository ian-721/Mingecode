# ADR-0011｜非生产 H5 Demo 实施授权

**状态：Accepted**  
**日期：2026-07-30**  
**授权人：赵焱阳**

## 背景

ADR-0001 与仓库既有门禁禁止在人工盲测前创建业务代码。该门禁用于防止研究尚未收口时提前固化产品，不应被静默绕过。

M1-BR v0.1 与 v0.2 已冻结混合译码方向、四个结构签名、十二个题槽、三至四题校准流程、四种关系状态以及前后台分离边界。项目现在需要一个可从头跑通的非生产 H5 Demo，验证真实排盘、最少校准、完整结果和分享回流能否形成产品闭环。

本轮不是公开上线，也不宣称命理或人格效度已经得到验证。

## 决定

在下列窄范围内，允许覆盖 ADR-0001 的业务代码禁令：

1. 从本 ADR 所在 PR 合并后的最新 `main` 创建 `feat/m1br-h5-demo`；
2. 建立移动端优先的 Next.js App Router + TypeScript 静态 H5；
3. 实现 `civil_time_v1`、四柱候选、四个结构签名、默认三道最多四道校准题、四种关系状态、完整结果和无敏感信息的分享卡/通用分享链接；
4. 运行时必须确定，不使用大模型裁决；
5. 原始出生资料只存在当前页面内存，不写入浏览器持久化、URL、日志、数据库或外部服务；
6. 用户无需登录即可获得完整结果；
7. 允许使用清楚、自然、不过度包装的临时 Demo 文案，但不得称为正式产品文案；
8. 允许增加必要的单元测试、端到端测试和构建配置；
9. 完成后只创建 Draft PR，等待 Work 验收。

实施必须遵守：

- `research/m1br/v0.3/BACKSTAGE_SIGNATURE_IMPLEMENTATION_CONTRACT_v0.1.md`
- `research/m1br/v0.3/H5_DEMO_PRODUCT_AND_ACCEPTANCE_SPEC_v0.1.md`

## 明确不授权

- 不部署生产环境；
- 不将业务 Draft PR 转 Ready 或合并；
- 不扩大为完整命理平台；
- 不增加微信小程序或原生 App；
- 不增加紫微、流年、神煞、纳音等体系；
- 不新增第 41 条人格规则；
- 不恢复已经退出的旧原型；
- 不增加数据库、API、认证、支付、会员、排行榜、好友匹配或复杂社交；
- 不默认保存出生资料；
- 不制作完整终局视觉系统；
- 不执行真人测试；
- 不宣称“已验证”“准确率”或科学人格效度；
- 不把后台术语、规则编号、精确分数、命盘或古籍页码暴露给用户。

## 实施与停止条件

只有以下最小工程路径获准：

- Next.js App Router；
- TypeScript；
- 静态导出；
- React 内存状态；
- 原生 CSS 或 CSS Modules；
- 锁定排盘依赖；
- Vitest 与 Playwright。

若锁定排盘依赖不能通过核心四柱与时间边界夹具、客户端确定性无法保持，或完成合同必须引入服务端、数据库或新的命理规则，执行立即停止并重新请求方案批准。不得自行更换架构或扩大范围。

## 验收与回滚

验收以产品规范中的功能闭环、隐私边界、固定夹具、移动/桌面适配和全部本地检查通过为准。

业务分支与 Draft PR 未合并前可直接关闭，线上没有影响。本 ADR 与两份合同保留为本次授权记录，不追写或删除旧 ADR。
