## 冻结决定

- 产品定位为基于传统八字结构的东方现代人格解释系统；
- MVP 只验证认领、保存、分享与邀请第二人的意愿；
- 第一版偏正向、偏娱乐、轻量易懂，同时保留真实阴影；
- 用户界面不展示未经验证的精确人格分数；
- 性别可选，但不参与核心人格裁决；
- 运行时采用确定性规则，大模型不承担人格裁决；
- MVP 不收集用户姓名；
- 用户无需注册或登录即可获得完整核心结果，分享、关注和联系方式不作为解锁条件；
- 默认不保存原始出生日期、时间和地点；
- MVP 默认使用 `civil_time_v1`，暂不启用真太阳时；见 [ADR-0008](DECISIONS/ADR-0008-mvp-civil-time-convention.md)；
- 所有规则结果、测试夹具和报告必须记录时间口径版本，不得静默混用；
- 赵焱阳与延雨婷的正式角色和决策边界；
- M1 人工盲测通过前不创建业务代码。

## 被覆盖的历史决定

历史 [项目规划](source/命格译码项目规划.txt)中的“MVP 不收集性别”被当前决定覆盖：性别可以作为可选解释层，但不得改变核心原型、特质排序或价值判断。原因与后果见 [ADR-0002](DECISIONS/ADR-0002-gender-as-optional-explanation-layer.md)。

历史 source 同时将“命格译码”作为产品名与工程名；当前品牌架构保留其内部工程身份，并将八字没一撇列为**候选 / Proposed / 待命名测试**的公开产品名。见 [ADR-0007](DECISIONS/ADR-0007-brand-architecture-and-public-name-candidate.md)。

当前品牌分层同时冻结命格译码 / Mingecode 的内部工程身份和“古人误会你了”的内容栏目身份；三者不得与公开产品名候选混写。

## 仍为候选或研究候选

- 公开产品名、类别说明和副口号均待命名测试；
- 4—6 个人格维度、6—8 个原型及 30—50 条规则均为研究候选；
- 传统判词到现代行为机制的映射待核验；
- 子时换日、时辰与节气边界、夏令时、历史时区、模糊出生时间及边界结果稳定性均待核验；
- 真太阳时是未来研究候选，当前排除在 MVP 默认路径之外；
- 三套轻量 Moodboard 和两个候选原型的视觉方向待验证；
- Next.js 等历史技术方案属于**后续技术候选，当前禁止实施**。
