# 候选规则治理

**状态：研究候选 / Research Candidate**

当前不存在已验证的正式规则库。本任务不虚构 30—50 条规则；M1 将基于可追溯来源逐条建立研究候选。

每条未来规则必须包含：

| 字段 | 要求 |
|---|---|
| Rule ID | 稳定且唯一 |
| 传统结构来源 | 可定位到来源登记 |
| 适用条件 | 明确触发边界 |
| 不适用条件 | 明确排除与反例 |
| 支持证据 | 支持该映射的材料 |
| 反向证据 | 冲突、反例或失败材料 |
| 行为机制解释 | 中性现代机制，不直接复制价值判断 |
| 可能的正向表现 | 有条件的资源表现 |
| 可能的失衡表现 | 有条件的代价表现 |
| 权重 | 仅供内部研究，不代表科学分数 |
| 冲突关系 | 与其他规则的优先、抑制或并存关系 |
| 版本 | 支持结果复现 |
| 审核状态 | 研究候选、待核验、排除或未来批准状态 |

规则不得由大模型自由裁决，不得因用户反馈临时迎合。性别只能用于传统历史语境解释，不得改变核心人格裁决。

使用[来源登记模板](SOURCE_REGISTER_TEMPLATE.md)和[争议日志模板](DISAGREEMENT_LOG_TEMPLATE.md)保留证据。
