## 本版结论

四份母本的内容方向通过产品验收，可以进入“从内容反推系统”的阶段；但它们仍不是四种已验证人格，也不能直接写进运行时。

本版冻结五件事：

1. 六个结构人格维度；
2. 四个样本型原型候选及其边界；
3. 八字证据合同；
4. 问题仅校准既有分岔的合同；
5. 确定性内容生成流程。

## 核心主从关系

```text
稳定命盘事实
→ 证据图
→ 结构张力
→ 核心人格机制
→ 辅助特质与显化分岔
→ 最多三道校准问题
→ 用户内容
```

命盘负责人格骨架与核心判断。问题不得从零生成原型，不得用答题多数推翻结构证据。

以下旧路线不得以新名称恢复为人格系统：

- 输入先行；
- 公开成稿；

它们可以作为局部行为或题目场景，但不足以定义完整人格。
