# 原型边界 v0.1

## 定位

本版只定义四个由母本反推的**候选原型机制**。它们不是完整分类表，也不要求所有命盘都归入其中。

核心原型描述的是“最能解释多个生活领域的主导结构张力”，不是最强十神，也不是最体面的标签。

## A01｜内生坐标型

**用户工作标题：** 自带坐标系的人  
**核心张力：** 自我生成方向很强，外部裁剪与现实接口相对不足。

必要条件：

- D1 为 `internally_generated`，且有两个独立证据家族支持；
- D6 出现 `expansive` 或 `closure_gap`；
- 外部约束、资源或输出至少有一项作为限制信号，而非完全缺席即自动成立。

排除条件：

- 长期依赖清晰权威才能行动；
- 开放问题显著失去方向；
- 内部输入与主体根气不足。

最近邻：

- 与 A04 的区别：A01 先重写坐标，A04 先编辑意义与价值；
- 与旧“输入先行”路线不同：A01 描述完整主体结构，不是准备习惯。

## A02｜高响应表达型

**用户工作标题：** 会发光，也会过热的人  
**核心张力：** 表达与环境响应强，但承载、恢复或自我保护不足以等量匹配。

必要条件：

- D2 为 `high_response_overheat`；
- 可见输出与评价/约束同时进入结构；
- 必须有容量或恢复限制，不能把强输出等同强承载。

排除条件：

- 对环境反馈长期低敏；
- 持续输出后无明显恢复需求；
- 只有表达强而无评价压力或容量张力。

最近邻：

- 与普通“外向型”不同：核心是响应与过热，不是社交偏好；
- 与 A04 不同：A02 首先处理气氛与出现，A04 首先处理完成度与价值。

## A03｜方法化压力型

**用户工作标题：** 内置质检部的人  
**核心张力：** 擅长把压力转成方法与质量，但内部审查会反过来限制行动和恢复。

必要条件：

- D3 为 `methodize_pressure`；
- D6 至少有 `sustained_builder`，并伴随内部否决或标准过载；
- 压力、输出方法与承载必须形成有效关系，不接受“见官杀+见食伤”机械判定。

排除条件：

- 面对模糊标准仍可无负担行动；
- 对验证、细节与复盘长期低敏；
- 压力没有转成方法，只表现为直接回避或服从。

最近邻：

- 与 A04 不同：A03 主要问“凭什么成立”，A04 同时问“有意义吗、值得吗”；
- 与旧“完成承诺”路线不同：A03 是压力加工机制，不是交接习惯。

## A04｜意义价值编辑型

**用户工作标题：** 灵感也要过验收的人  
**核心张力：** 想让意义、审美与现实价值同时成立，因此既能做精，也容易过早验收。

必要条件：

- D4 为 `meaning_value_editor`；
- D6 出现 `premature_gatekeeping` 或高完成度要求；
- 意义/输入、表达能力与现实价值接口均有有效证据。

排除条件：

- 长期不在意质感、完成度或实际价值；
- 只有现实资源敏感而无意义/审美通道；
- 只有想象与表达而无现实验收张力。

最近邻：

- 与 A03 不同：A03 由压力驱动方法，A04 由意义与价值的双重标准驱动编辑；
- 与 A01 不同：A01 容易扩张世界观，A04 容易让新芽过早参加验收。

## 原型裁决门

只有以下条件全部满足才可输出核心原型：

1. 至少三个结构维度形成同一可解释机制；
2. 至少两个独立证据家族支持核心张力；
3. 有明确反向信号，且不足以推翻核心；
4. 该机制可同时解释至少三个领域：自我、关系、行动/表达；
5. 与最近邻存在一条明确不可互换的边界；
6. 所有合理时间候选盘均保持同一核心方向。

否则输出：

- 两个候选机制；或
- 只输出结构特质，不授予核心原型；或
- 时间边界敏感，暂不定稿。

不得为了让每个人都有卡片而强制覆盖。
