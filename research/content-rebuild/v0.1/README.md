# 命格译码｜内容体系重建 v0.1

**状态：** Draft / Research Candidate / Not Human-Tested  
**范围：** 只重建内容母本，不修改 UI、业务代码、依赖、部署或现有 Demo。  
**核心原则：** 命盘负责给出人格骨架与核心判断；问题只用于校准命盘内部的模糊分岔。

## 为什么重建

现有 Demo 把命盘降为起题顺序，再由四到六道工作场景题决定结果，导致：

- 八字在结果中几乎缺席；
- 人格被压缩成项目推进习惯；
- “古人误会你了”没有具体传统结构可翻译；
- 文案正确但没有人味、笑点和认领感。

本目录先用四个匿名真实命盘制作内容母本，验证“什么内容值得实现”，再反推维度、原型、规则和校准问题。

## 文件

- `CONTENT_MODEL.md`：命盘主导、问题辅助的内容合同；
- `SAMPLE_01.md`—`SAMPLE_04.md`：四份匿名内容母本；
- `EVIDENCE_TO_CLAIM_MAP.md`：证据与用户判断的映射；
- `CONTENT_ACCEPTANCE.md`：产品验收与停止条件。

## 边界

- 四份样本不是已验证人格类型；
- 不根据熟人经历反向改写命盘规则；
- 不把十神数量直接等同人格；
- 不做吉凶、婚姻、财富、健康或事件预测；
- 不进入代码实现，直到内容母本通过产品验收。
