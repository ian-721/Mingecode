# 内容母本验收 v0.1

## 1. 当前验收对象

- `SAMPLE_01.md`—`SAMPLE_04.md`
- 只验内容方向，不验规则引擎准确率；
- 不执行真人盲测，不改 Demo。

## 2. 单份通过条件

每份必须同时满足：

- 命盘是核心判断来源，问题仅校准；
- 至少两个独立证据家族；
- 有一个清晰的内在矛盾；
- 高光与翻车来自同一机制；
- 覆盖工作、关系和自我体验；
- 至少三条可明确否认的行为判断；
- “古人误会”对应具体传统结构，不是空口号；
- 至少一句自然、有趣、值得截图；
- 去掉样本身份后仍与其他三份明显不同。

## 3. 横向区分检查

遮住四柱和标题后，检查四份是否仍分别呈现：

- S01：自生坐标、扩张与裁剪困难；
- S02：表达感染、评价响应与能量过热；
- S03：方法化压力、质量控制与内部否决；
- S04：意义—价值双重验收、审美与现实张力。

若任意两份只需替换少量名词即可互换，退回重写。

## 4. 失败条件

出现以下任一项立即停止进入规则实现：

- 读起来仍像咨询报告、项目管理培训或 MBTI 套话；
- 去掉八字入口后与普通人格测试无区别；
- 主要依靠“有时……有时……”覆盖所有人；
- 为了有趣而写成与命盘无关的段子；
- 为了显得准确而使用已知人物经历补洞；
- 需要新增命理规则才能解释已写好的文案；
- 不能回答“为什么这句话来自这张盘”。

## 5. 通过后的唯一下一步

母本通过后，反向拆出：

```text
人格维度
→ 原型边界
→ 八字证据合同
→ 校准题
→ 确定性生成规则
```

在此之前，不修改现有四路线题库和结果代码。
