# 冲突裁决合同 v0.1

## 唯一裁决顺序

```text
0. 事实与时间有效性
1. G01 证据去重
2. G02 时间稳定
3. 原型排除规则
4. 原型支持规则
5. 核心张力规则
6. G03 反证与最近邻边界
7. G04 证据充分性
8. 显化校准
9. 内容块组装
```

不得调换顺序。尤其不得先根据用户回答或文案吸引力选择原型，再回头寻找命盘证据。

## 1. 时间优先

- 合理候选盘改变核心方向：直接 `boundary_sensitive`；
- 候选盘只改变辅助特质：保留核心，对该辅助特质降级；
- 未知时柱：不补造时柱；只有三柱已满足核心门且未知部分不能合理推翻时，才允许保留 `candidate`，不得升级为 `established`。

## 2. 排除优先于支持

命中原型排除规则时：

- 两条支持全部成立也不能输出 `established`；
- 若排除证据较弱或只在一个候选盘出现，输出 `conflicted/boundary_sensitive`；
- 不允许用问题答案覆盖排除规则。

## 3. 单原型裁决

一个原型需同时满足：

- 两条支持规则 `established`；
- 张力规则 `established`；
- 排除规则 `not_supported`；
- G01—G04 通过。

缺一项：最多为 `candidate`。

## 4. 双原型冲突

两个原型同时通过初步门时，依次比较：

1. 哪一个核心张力能解释更多独立维度；
2. 哪一个拥有更强的 E1/E3/E4 链路证据；
3. 哪一个最近邻排除条件更清楚；
4. 哪一个反证更少且不触及核心；
5. 时间候选是否始终保持同一优先级。

仍无法区分时必须输出双候选，不得用答题多数票、固定优先级或更好听的名称强行单选。

## 5. 近邻不可互换边界

- A01 vs A04：A01 先重写坐标；A04 先编辑意义与价值。
- A02 vs A04：A02 首先响应气氛和反馈；A04 首先判断完成度与价值。
- A03 vs A04：A03 由压力驱动方法；A04 由意义与价值双重验收驱动编辑。
- A01 vs A03：A01 在开放空间中扩张；A03 在压力空间中收紧并方法化。

## 6. 问题答案冲突

当回答与核心原型典型表现相反：

- 标记为后天补偿、场景差异或显化抑制；
- 允许调整辅助特质顺序；
- 不改变核心原型和独立证据家族；
- 若回答使核心声明完全不可否认，应删除该声明，而不是重写成双面句。

## 7. 输出状态

| 条件 | 输出 |
|---|---|
| 单一原型全部通过 | `established` 核心原型 |
| 单一原型缺一项非核心门 | `candidate` + 保留语气 |
| 两原型均有强证据且边界不清 | 双候选 |
| 支持与关键反证同强 | `conflicted` |
| 候选盘改变核心 | `boundary_sensitive` |
| 无原型满足门 | 结构特质，不授予原型 |
