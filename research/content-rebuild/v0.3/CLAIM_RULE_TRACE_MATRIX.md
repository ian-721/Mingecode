# 声明—规则追踪矩阵 v0.2

本表不改写已通过内容，只重标声明权限。`skeleton` 可由静态结构支持；`manifestation` 必须经过核心冻结后的有限问题校准；`auxiliary` 不参与核心。

| 内容键 | 静态 skeleton 绑定 | manifestation / auxiliary 权限 | 明确禁止 |
| --- | --- | --- | --- |
| `A01.core.coordinate` | A01-R01/R02；D1/D6；C01/C02 | “内部坐标”仅为现代翻译 | 声称人格或行为被命盘单独证明 |
| `A01.tension.expansion` | A01-R03 只支持连续供能—受限收束张力 | 扩张、裁剪、重写问题需问题 | 将 expansion/pruning 写成事实节点 |
| `A01.relationship.autonomy` | 无核心权限 | auxiliary / manifestation | 补核心维度或最近邻 |
| `A01.crash.rewrite` | 无核心权限 | 重开地图、重写行为需问题 | 静态盘证明行为频率 |
| `A02.core.response` | A02-R01/R02；D2/D5；C03 | 环境、气氛、反馈响应需问题 | 把环境敏感作为边属性 |
| `A02.tension.overheat` | 只支持输出—主体容量不对称 | 耗电、恢复需问题 | `recoveryCapacity` 或健康结论 |
| `A02.relationship.feedback` | 无核心权限 | auxiliary / manifestation | 反馈进入证据家族 |
| `A02.crash.feedback_as_power` | 无核心权限 | manifestation | 答案改变 A02 核心 |
| `A03.core.method` | A03-R01/R02；D3/D1；C04/C01 | 方法化、质检、首版延迟需问题 | 压力必然变方法 |
| `A03.tension.review` | A03-R03 只支持中介交接结构 | P06 全部 manifestation | P06 计维度、家族或张力 |
| `A03.relationship.reliability` | 无核心权限 | auxiliary / manifestation | 抬高为第三维度 |
| `A03.crash.infinite_review` | 无核心权限 | manifestation | 命盘单独证明无限审查 |
| `A04.core.editor` | A04-R01/R02；D4/D6；C05 | 意义价值双验收需问题 | 双验收作为原子事实 |
| `A04.tension.early_gate` | A04-R03 只支持转换交接结构 | P08 全部 manifestation | stage/completion 虚构字段 |
| `A04.relationship.quality_exchange` | 无核心权限 | auxiliary / manifestation | 抬高为第三维度 |
| `A04.crash.no_trial_period` | 无核心权限 | manifestation | 命盘单独证明淘汰灵感 |

母本或快照中同一块混合两层时，未来只可按批准子块过滤；未实现过滤前，不得把 manifestation 句段标为 chart-established。传统归因全部继续遵守 v0.4 `pending_source`。
