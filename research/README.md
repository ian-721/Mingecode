# 研究区

**状态：研究治理 / Accepted**

当前所有人格维度、原型和规则都是**研究候选**，不存在已验证的正式人格体系或正式规则库。研究材料不得直接用于公开预测、吉凶判断或人生决策。

M1 的核心是验证区分度，不是扩大命理体系。研究必须：

- 记录来源、适用与不适用条件、支持与反向证据；
- 区分传统结构描述与古代价值判断；
- 保留冲突、反例和待核验事项；
- 先执行纯内容盲测，再考虑完整视觉制作；
- 禁止虚构规则、用户反馈、盲测结果、命理共识或科学准确率；
- 保持性别中立的核心人格裁决；
- 不把内部连续权重包装成心理测量学量表。
