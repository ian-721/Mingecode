# 研究区

**状态：研究治理 / Accepted**

当前所有人格维度、原型、结构签名和规则都是**研究候选**，不存在已验证的正式人格体系或正式规则库。研究材料不得直接用于公开预测、吉凶判断或人生决策。

M1 的核心是验证区分度，不是扩大命理体系。研究必须：

- 记录来源、适用与不适用条件、支持与反向证据；
- 区分传统结构描述与古代价值判断；
- 保留冲突、反例和待核验事项；
- 先执行纯内容与流程验证，再考虑完整视觉制作；
- 禁止虚构规则、用户反馈、盲测结果、命理共识或科学准确率；
- 保持性别中立的核心人格裁决；
- 不把内部连续权重包装成心理测量学量表；
- 不因已有命名、视觉或文案投入保留缺乏区分依据的候选。

## 当前研究方向

M1-BR 采用混合译码：命盘提出最多三个结构签名候选，默认三道、最多四道现实行为校准题用于消除近邻歧义。问题不是长问卷，不生成心理量表分数。

前后台分离：后台保留时间、结构、冲突、来源和不确定性研究；前台只保留轻量输入、三道题、易认领结果和分享入口。
