# 研究区

**状态：研究治理 / Accepted**

当前所有人格维度、原型、结构签名和规则都是**研究候选**，不存在已验证的正式人格体系或正式规则库。研究材料不得直接用于公开预测、吉凶判断或人生决策。

研究必须：

- 记录来源、适用与不适用条件、支持与反向证据；
- 区分传统结构描述与古代价值判断；
- 保留冲突、反例和待核验事项；
- 禁止虚构规则、用户反馈、盲测结果、命理共识或科学准确率；
- 保持性别中立的核心人格裁决；
- 不把内部连续权重包装成心理测量学量表；
- 不因已有命名、视觉或文案投入保留缺乏区分依据的候选。

## 当前研究方向

当前 H5 `/test` 继续按 ADR-0012 与 R2 合同运行：命盘只负责起题，四至六题独立裁决现实路线。content-rebuild 是隔离的静态研究线，不改变该运行模型。

content-rebuild v0.5 为 Proposed 合同候选：完整保留 atomic occurrence closure，再投影为六个 relation interfaces；正常 multiplicity 不构成 competition，只有显式且可验证的 contention fact 才能产生冲突。该候选不授权代码、页面、PR #16 同步或部署。

前后台分离继续有效：后台保留时间、结构、冲突、来源和不确定性；前台只使用当前已授权运行合同允许的信息。

ADR-0011 已窄范围授权非生产 H5 Demo，将现有研究转成真实可操作闭环。该授权不代表真人验证完成，不允许部署或宣传准确率。
