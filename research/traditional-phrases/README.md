# 传统判词翻译研究

**状态：研究候选 / Research Candidate**

传统判词只能作为研究材料，不能直接成为用户结论。处理时必须：

1. 区分可观察的结构描述与古代价值判断；
2. 记录历史社会角色、性别规范和流派语境；
3. 将结构先翻译为中性的行为机制；
4. 同时保留可能资源、适用条件、边界和代价；
5. 记录支持证据、反向证据与待核验问题。

不得直接向用户展示“克夫、无子、贫命、短命”等恐吓、歧视或宿命词语。现代翻译也不能只是正面洗白；如果一种机制在特定情境下可能失衡，必须温和而真实地说明。

传统性别语境只用于解释古代为何给予不同评价，不得改变核心原型、特质排序或价值高低。
