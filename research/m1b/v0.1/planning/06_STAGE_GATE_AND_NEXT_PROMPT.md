# 06｜阶段门结论与下一轮启动提示词

## 1. 本轮判断

### M1-A 入库

**可规划、不可直接静默写入。**  
正确方式是建立不可变原始快照、外层状态说明、SHA-256 清单、差异报告和 Draft PR 人工门。

### M1-B 材料准备

**可以进入下一轮执行。**  
执行范围仅包括来源校勘、规则定义、抽象夹具、八份报告母本、控制文本、错配算法、随机化与预注册冻结。

### 真人盲测

**不准入。**  
必须等 M1-B 全部材料完成、生成统一哈希、通过人工检查，并由赵焱阳另行明确授权。

### 业务开发与完整视觉

**不准入。**  
不创建 H5、排盘代码、规则引擎、数据库、API、部署、CI 或完整视觉系统。

## 2. 下一轮可复制启动提示词

```markdown

请将本对话标题设置为：

项目仓库：`ian-721/Mingecode`

4. 全程保持“六维、八原型、40 条规则、12 条翻译样带均未验证”的状态。

- 逐条审查 M1-A 候选；
- 冻结来源、规则和时间定义；
```
