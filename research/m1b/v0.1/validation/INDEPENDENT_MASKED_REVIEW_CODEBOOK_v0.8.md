## 3. 中心机制复述判据

独立评审者不必使用项目术语，但复述至少应命中以下对象之一：

```text
A：接收/完成/后续责任
B：权限/标准/角色主次
C：外化/可见版本/回应
D：输入条件/背景/第一版之前
```

### 最低通过

- 至少 3/4 份复述命中对应对象；
- A、C、D 三份必须分别识别出“完成接口”“公开外化”“首版前输入”三个不同流程位置；
- 不得把 B 仅概括为“更成熟、更会合作”。

## 4. 高风险近邻

映射后的危险对为：

```text
D ↔ C  = R01 ↔ R02
首版形成前的输入顺序 vs 判断形成后的公开外化

C ↔ A  = R02 ↔ R04
可观察外部版本 vs 被具体对象接收并形成完成/责任接口

B ↔ A  = R03 ↔ R04
决定权与标准主次 vs 接收对象与完成责任终点
```

### 强制合并门

任一独立评审者出现下列情况，相关对进入 `merge_or_delete_required`：

- D/C 写“不能区分”，或只用“一个慢、一个快”“一个内向、一个外向”区分；
- C/A 写“不能区分”，或把两者都概括为“做成结果/交付”；
- B/A 只能靠“权限”和“责任”两个抽象词区分，无法写出谁拍板与什么算完成的动作差异；
- 合并理由主要是文本长度、文采或喜欢程度，而不是对象与流程位置。

### 单评审者判据

若同一文本在以下六题中被选为最高 3 次或以上，则记为 `prestige_imbalance_detected`：

```text
能力更强
更成熟/会合作
更负责/可靠
最像职业技能
正向最有吸引力
代价最像温柔缺点
```

“无法区分”不自动算通过；评审者必须说明是否确实等质，还是四份都同样抽象。

### 多评审者判据

若两名评审者均把同一文本判为能力、成熟或责任声望最高，直接触发重写；若两名对近邻是否可区分意见相反，保守按未通过处理。

## 6. 可否认性门

每份必须得到至少一个与正文反向条件一致的明确行为：

```text
A：有可见输出即可，不关心接收对象、完成标准或后续责任
B：权责和标准模糊时也几乎不需要澄清即可稳定协作
C：判断形成后仍很少外化，长期只在内部加工
D：信息很少、背景缺失时仍能稳定直接定稿
```

只写“我不是这样的人”或抽象反义词不算完成。
