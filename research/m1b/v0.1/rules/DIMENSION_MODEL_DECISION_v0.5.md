# CRX-0.5｜六维独立性诊断与机制域重构决定

**状态：** Research Model Decision / Proposed  
**对象：** M1-A 六个候选维度  
**结论性质：** 材料层收束，不是人格效度结论

## 1. 原六维进入报告前的既定门

每个维度至少需要：

- 6 条不含命理术语的可观察行为；
- 2 个可否定反例；
- 2 个相对独立的结构证据家族；
- 与相邻维度的判别问题；
- 两端各自的资源与代价；
- 不依赖职业、性别、精英或创业叙事。

40/40 规则首轮审查和跨批次回归后，没有任何原维度满足“两个独立家族”门。

## 2. 六维逐项裁决

| 原维度 | 主要候选 | 独立家族状况 | CRX-0.5 决定 |
|---|---|---|---|
| D1 主体边界 | 018、020/038；017已降级 | 高度集中于`CL-REFERENCE-CONSTRAINT` | 不作为独立连续维度冻结；保留为“参照—约束接口”机制域 |
| D2 感受吸收 | 011、012及印相关modifier | 与D4共享`CL-INPUT-OUTPUT`；“情绪/背景吸收”无独立规则 | 取消独立维度资格；并入输入—输出路由的输入侧 |
| D3 探索启动 | 原033、食伤/冲映射均已删除 | 0个可释放家族 | 淘汰当前版本；不得用冲、伤官或食伤补洞 |
| D4 表达推进 | 012、014、021/022、023/024 | 候选较多但集中于输出与压力接口，端点重复 | 保留为输入—输出/压力接口机制，不作单一高低轴 |
| D5 现实转化 | 026、027及025/024 modifier | 主要集中于`CL-REALITY-CONVERSION` | 保留为“完成—承诺路由”机制域，禁止商业/财富化 |
| D6 承载节律 | 001/002/006背景，016/029负荷，039综合门 | 无独立正向家族；多为gate | 降级为全局容量/负荷守门，不作为人格维度 |

## 3. 六维模型阶段判断

```text
six_dimension_model_status: not_advanced
reason: independence_gate_failed
frozen_user_facing_dimensions: 0
```

这不是证明六维“错误”，而是现有40条规则不足以让六维以相对独立、可执行的方式进入报告。继续保留六个轴会导致：

- D2、D4、D5重复使用同一食伤/财链；
- D1过度依赖比劫官杀叙事；
- D3靠冲或食伤被强行补出；
- D6把容量守门包装成“稳定、长期、可靠”的高声望人格。

## 4. 提议的三机制域 + 三修饰/守门结构

下一轮材料不再用六个连续维度生成报告，而使用三个候选主机制域：

### M-A｜输入—输出路由

回答：内部材料是否形成输出、以何种方式显现、是否被过滤。

候选规则：012、014、021/022、023/024；011/015为修饰，013为反向候选。

### M-B｜参照—约束接口

回答：自我参照、外部标准和多重规范如何形成可协商、未解决或已解决状态。

候选规则：018、020/038；019为修饰。017不再作为核心。

### M-C｜完成—承诺路由

回答：输出是否进入明确完成对象，完成是否进一步形成规则、责任或后续承诺。

候选规则：026、027；025、024、028为修饰。

同时保留三个不增加核心证据的层：

### G-1｜容量与负荷守门

001/002/006/008、016/029、007/039。只判断主链是否可持续释放，不定义“稳定人格”。

### M-1｜显隐修饰

004/005/009/010/015/037。只调整公开、条件可见和声明强度。

### M-2｜关系与时间敏感性

003、031—036、040及时间协议。只进入敏感性附录，不定义人格。

## 5. 对八个原型的直接影响

| 原型 | 原主要机制 | 当前裁决 |
|---|---|---|
| P01 先手试路人 | D3探索启动 | **Hold / Redesign**：核心机制无可释放家族 |
| P02 深层收音机 | D2感受吸收 | **Hold / Narrow**：只能收窄为输入偏置/延迟输出，情绪与未说出口背景暂无依据 |
| P03 明牌表达者 | D4表达推进 | **Conditional Candidate**：可围绕012/014与压力接口重写 |
| P04 稳态维护者 | D6承载节律 + 低D3 | **Hold / Redesign**：没有正向维护家族，不能由容量背景推出可靠维护 |
| P05 接缝协调员 | 多维组合 | **Secondary Composite Only**：可由018+024/027/028组合，但不能作为独立核心原型 |
| P06 自带门框者 | D1主体边界 | **Conditional Candidate**：可围绕018及020/038重写；删除017式“约束缺失”推断 |
| P07 收口成品人 | D5现实转化 | **Conditional Candidate**：可围绕026/027重写，删除商业/效率声望 |
| P08 慢变量养成者 | D6 + D2 | **Hold / Redesign**：长期积累与固定节律无独立规则家族 |

## 6. 对盲测规模的影响

当前只有 P03、P06、P07 具备相对清晰的候选主机制；P02可作为待重写输入侧候选，P05只能作为组合型辅助特质。P01、P04、P08缺主机制。

因此：

```text
8-persona_content_lock_allowed: no
48-person_8x6_preregistration_ready: no
```

下一步必须在以下两条路径中择一，且都不得在本阶段自行冻结：

1. **定向补研究**：只为探索/维护/长期积累寻找真正独立且可反驳的结构机制；找不到则淘汰；
2. **缩小候选模型**：围绕三个主机制域重建6个以内的状态型原型，而不是保留原八原型名称。

## 7. 保护原则

- 不因八原型视觉已存在而保留缺证据原型；
- 不因P03/P07更容易写成高声望职业叙事而优先保留；
- 不用关系类或综合门补齐D3/D6；
- 机制域仍只是研究候选，不是已验证人格维度。
