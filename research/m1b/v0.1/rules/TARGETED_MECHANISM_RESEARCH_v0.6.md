# CRX-0.6｜探索、维护与长期积累定向机制研究

**状态：** Completed as Draft Research Decision  
**对象：** P01、P04、P08 及其原维度/规则依赖  
**原则：** 不为保留原型新增漂亮规则；找不到独立结构家族即淘汰核心资格

## 1. 研究问题

分别检验以下三种叙事是否能从现有40条规则中获得：

1. 至少一个对象明确、可执行、可反驳的主机制；
2. 至少两个互不重复的结构家族；
3. 明确反例和关闭条件；
4. 不依赖职业、成功、创造力或道德声望；
5. 不借关系标签、时间敏感性或综合门充当核心证据。

## 2. P01｜探索启动 / 先手试路

### 检查过的候选

- `MC-R-033` 势均之冲：仅为关系敏感性，不能推导探索、试验或爱变化；
- `MC-R-014` 公开输出：只说明输出可见，不说明愿意进入未知；
- `MC-R-022` 重定义压力：只作用于特定压力对象，不等于普遍探索；
- 食伤、伤官、冲、合等标签：均不能自动产生启动偏好。

### 缺失

现有规则没有稳定回答：

```text
面对未知是否更愿意先行动
是否偏好小试验而非完整规划
是否会因新鲜感持续换轨
何种结构反例能否定探索倾向
```

### 决定

```text
P01_core_status: retired_from_M1B
D3_exploration_status: removed_from_current_model
future_research: allowed_only_with_new_independent_source_and_rule_family
```

P01可以保留为历史创意资产，但不得进入候选报告、错配池或视觉投入。

## 3. P04｜稳定维护 / 长期可靠

### 检查过的候选

- `MC-R-001/002/006`：只提供容量与根气背景，不证明维护偏好；
- `MC-R-027`：只描述成果进入正式承诺，不证明重复维护；
- `MC-R-039`：只是多路由开放综合门，不证明可靠或持续；
- 低探索或关系稳定：不能反向推出维护人格。

### 缺失

现有规则没有稳定回答：

```text
是否偏好重复维护而非新建
是否主动关注交接、遗漏和长期可用性
何时会继续修补而不换轨
维护倾向的独立反例是什么
```

### 决定

```text
P04_core_status: retired_from_M1B
maintenance_dimension_status: not_supported
```

“让系统明天仍可用”“长期可靠”等文案全部撤出候选报告。

## 4. P08｜长期积累 / 慢变量

### 检查过的候选

- `MC-R-011/012`：输入与加工顺序，不证明长期坚持；
- `MC-R-001/002/006`：容量背景，不证明延迟回报偏好；
- `MC-R-039`：综合开放门，不证明复利、耐心或固定频率；
- 负荷与恢复规则：只作守门，不能反推长期主义。

### 缺失

现有规则没有稳定回答：

```text
是否偏好延迟回报
是否能在低反馈阶段维持固定频率
何时坚持会转成路径依赖
什么结构能区分长期积累与单纯惯性
```

### 决定

```text
P08_core_status: retired_from_M1B
long_horizon_dimension_status: not_supported
```

P08不得再通过“印旺、根多、身旺、路由齐备”回填。

## 5. P05｜接缝协调的定位

P05可由以下机制组合出现：

- 018 可谈判边界；
- 024 表达—标准桥接；
- 027 完成—承诺；
- 028 约束—内部支持。

但它没有独立结构家族，因此：

```text
P05_core_status: retired_as_core
P05_secondary_status: conditional_composite_trait
minimum_conditions: at_least_two_distinct_main_mechanisms
new_evidence_contribution: 0
```

不得用“跨专业协调”“看见所有接口”等职业能力声望包装。

retired_core_reports: P01, P04, P08
