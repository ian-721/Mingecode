## 1. 审查口径

本批审查“输入—输出路由、表达通道、输出负荷、自我参照与外部约束”十条规则。审查目标不是证明十神具有现代人格效度，而是判断候选规则是否具备一致触发、排除、去重、反例、时间边界和报告释放条件。

正式出版版本、原文/评注分栏与页码仍未关闭。因此：

- 本批不产生 `eligible_core`；
- 结构定义已接近可执行且原本承担锚点作用者，标记 `pending_source`；
- 只能修饰声明、不独立决定原型者，可标记 `eligible_modifier`；
- 仍依赖全局缺失、力量比较、关键通道或后续互斥规则者，标记 `pending_definition`。

## 3. 逐条审查

### MC-R-011｜印有根透出且输出弱

- **原始候选作用：** D2 感受吸收偏高、D4 表达偏内化；支持 2。
- **可保留结构事实：** 至少一条有效输入/支持路径存在，同时经完整检查后没有有效外显输出路径。
- **主要问题：** “印”在传统材料中同时承载生扶、文书、身份等语义，不能直接翻译为理解力、感受深度或学习能力；“食伤弱”也不能只看天干是否出现。
- **派生层修正：** 只允许生成 `input_before_output = candidate` 的条件性修饰。必须使用 v1.1 的 `output_weak` 检查，且不能单独提升 D2。
- **互斥/覆盖：** 与 012 对输出状态互斥；若 013 的关键输出被过滤成立，由 013 的更具体机制接管，不再使用 011 的一般叙事。
- **反例：** 食伤虽少，但有根、连续链或稳定替代输出存在时不触发。
- **可否认行为候选：** 面对新材料时是否常先收集背景、延迟给出第一版；该句仍须由另一独立家族共同支持。
- **禁用推断：** 学习能力强、敏感、聪明、学历高、记忆好、内心丰富。
- **审查状态：** `eligible_modifier`。

### MC-R-012｜印食并存且不直接冲突

- **原始候选作用：** D2 高吸收、D4 中高表达；锚点 3。
- **可保留结构事实：** 有效输入路径能够经日主承接后到达有效输出，且没有被完全过滤或破坏。
- **主要问题：** “印食并存”不能按数量判定；同一食伤事实可能同时被 012 与 014 重复当作两份证据。
- **派生层修正：** 定义为 `input → internal processing → output` 的连续路由候选，主家族为 `EF-INPUT-OUTPUT-ROUTING`。它最多提供一个锚点候选，不能同时把输入、输出拆成多个独立人格分数。
- **互斥/去重：** 与 011、013 对同一关键输出状态互斥；与 014 同属 `CL-INPUT-OUTPUT`，若共享食伤链，核心计数上限为 1。
- **反例：** 印到身但食伤虚浮；食伤存在但被偏印关键过滤；财破印导致输入链断裂；任一节点不稳定。
- **可否认行为候选：** 在理解复杂材料后，是否通常能产出一个可供他人回应的版本，而不是只继续收集或只快速反应。
- **禁用推断：** 天生会讲课、知识型人格、聪明且会表达、一定擅长内容工作。
- **审查状态：** `pending_source`；来源门关闭后才可评估锚点槽。

### MC-R-013｜偏印有效制食

- **原始候选作用：** D4 表达受过滤、D2 感受吸收偏高；锚点 3。
- **可保留结构假设：** 一条主要输出路径可能被有效的内部解释/保护路径直接过滤。
- **主要问题：** “偏印与食神同现”远不足以触发；必须证明食神是关键输出、作用直接、没有替代输出，且偏印不是必要扶身。原文对 D2 的自动提升缺乏独立依据。
- **派生层修正：** 删除 D2 自动加权，只保留 D4 过滤/审查候选。只有 `key_output_channel` 与 `direct_filtering` 同时通过时才可继续。
- **互斥/覆盖：** 命中后关闭 012；若只是一般输出弱而无法证明直接过滤，则退回 011；财有效制印、另有伤官出口或食神非关键时关闭。
- **反例：** 偏印虽强但承担必要支持，食神另有多根或独立出口，实际输出不受阻。
- **可否认行为候选：** 暂不进入报告；未来必须能区分“先审查后输出”与“根本没有输出兴趣”。
- **禁用推断：** 心理问题、压抑、克子、没福、身体差、创作受诅咒。
- **审查状态：** `pending_definition`。

### MC-R-014｜食伤有根透出且容量足

- **原始候选作用：** D4 表达推进偏高；D3 可能偏高；锚点 3。
- **可保留结构事实：** 一条有根、可达且未被关闭的输出通道在天干层公开可见，并有基本承载。
- **主要问题：** 输出存在不等于外向、口才、创意或探索；D3 不能由同一食伤信号自动增加。与 012、016 有相关依赖。
- **派生层修正：** 只生成 `output_channel = public_and_supported`。D4 锚点候选仅表示“内部材料较可能形成可观察输出”，D3 必须由独立家族提供。
- **互斥/去重：** 与 015 对同一输出功能互斥；若透而无根由 009 接管；与 012 共享链时依赖簇最多计一份正向证据；可与 016 共存，但 016 只作负荷守门。
- **反例：** 食伤透而无根、被有效制尽、日主承载不足且形成过载，或关键根位于不稳定时间边界。
- **可否认行为候选：** 在形成观点后，是否较常把它变成文字、作品、样例或明确反馈，而不是只留在内部。
- **禁用推断：** 外向、口才好、艺术天赋、叛逆、社交活跃、创新者。
- **审查状态：** `pending_source`；来源门关闭后才可评估 D4 锚点槽。

### MC-R-015｜食伤藏而不透

- **原始候选作用：** D4 在私域或熟悉场景外显；细节 1。
- **可保留结构事实：** 输出候选只在藏干层存在，没有公开外显通道。
- **主要问题：** 藏干存在不能证明“私下很会表达”；从结构无法直接读出熟人、私域或低压力情境。
- **派生层修正：** 只记录 `output_visibility = latent_or_conditional`。没有另一条规则提供稳定激活情境时，不生成用户行为声明。
- **互斥/覆盖：** 与 014 互斥；若满足 010 的无透无引，采用 010 的更严格“不写入报告”守门；不能与 005 的一般藏而不透重复计数。
- **反例：** 合会、透出或连续链已使输出公开有效时关闭。
- **可否认行为候选：** 仅在另有情境证据时，才能测试“是否在特定熟悉环境更容易输出”。
- **禁用推断：** 隐藏创作者、熟人面前很活泼、只是没有被发现的天才。
- **审查状态：** `eligible_modifier`。

### MC-R-016｜输出负荷超过承载

- **原始候选作用：** D4 表达高、D6 承载偏脉冲；锚点 3。
- **可保留结构假设：** 有效输出占用的容量可能高于现有恢复路径，形成节律风险。
- **主要问题：** “食伤强”“支持不足”“持续消耗”仍缺统一比较阈值；严格特殊结构排除也尚未完成。不能用身弱标签替代比较。
- **派生层修正：** 只作 `EF-OUTPUT-LOAD` 负向守门。它不增加 D4 正向证据，也不能独立断言高产或反应快。
- **共存/去重：** 可与 014 共存；014说明通道存在，016只说明节律风险。与后续财链、恢复链规则需做互斥和减弱测试。
- **反例：** 有效财链完成收口、比印恢复充分、输出并不持续，或候选盘只在边界时间下显示过载。
- **可否认行为候选：** 暂不进入报告；未来需区分“输出后需要较长恢复”与现实作息、健康、工作量等外部因素。
- **禁用推断：** 能量低、能力弱、会 burnout、身体差、工作不持久。
- **审查状态：** `pending_definition`。

### MC-R-017｜比劫有根且外部约束弱

- **原始候选作用：** D1 主体边界偏内定标；支持 2。
- **可保留结构假设：** 有效自我/同类参照存在，而外部约束路径较弱时，判断中心可能较少依赖外部标准。
- **主要问题：** 比劫根气与 001/002/006 的容量事实高度重叠；“官杀弱”是全局否定命题；财负荷可能把同一结构改写为资源竞争。
- **派生层修正：** 建立 `effective_self_reference` 与 `constraint_weak` 两个独立门。容量家族只作为前置条件，不能再算第二份边界证据。
- **互斥/依赖：** 与 018 对外部约束状态互斥；若后续 030 的资源竞争条件完整，017 必须关闭或改写；从强候选仍排除。
- **反例：** 官杀虽不透但有根、有印化/食制路径；比劫主要承担资源争夺；自我参照只有名义数量。
- **可否认行为候选：** 暂不进入报告；未来需具体测试“面对规则与个人判断冲突时，默认先校验哪一方”。
- **禁用推断：** 独立、强势、不服管、适合创业、好胜、难合作。
- **审查状态：** `pending_definition`。

### MC-R-018｜比劫与官杀双向有效

- **原始候选作用：** D1 主体边界为可谈判边界；锚点 3。
- **可保留结构事实：** 自我参照与外部约束两端都有效，且存在中介路径，不是一方完全压倒另一方。
- **主要问题：** “双向有效”不能用数量平衡代替；协商、合作和成熟不是结构事实。与 019 可能复用同一官杀证据。
- **派生层修正：** 定义为 `negotiated_boundary_candidate`，要求两端有效、中介路径成立、无官杀混杂失序、无直接未解决相战。
- **去重：** 与 017 互斥；与 019 同属 `CL-REFERENCE-CONSTRAINT`，若复用同一官杀路径，不能自动算两个独立家族。
- **反例：** 官杀一方虚浮、比劫被制尽、两端直接冲突无中介、或官杀混杂未解决。
- **可否认行为候选：** 在权限清楚的合作中，是否能接受标准但仍要求保留明确的自主决定区。
- **禁用推断：** 高情商、成熟、善协作、管理能力强、平衡型人格。
- **审查状态：** `pending_source`；来源门关闭后才可评估 D1 锚点槽。

### MC-R-019｜单清官杀且有承接

- **原始候选作用：** D1 外部校准增强，D6 责任承载可能增强；支持 2。
- **可保留结构事实：** 一类有效约束形成主导，并能通过印、食制或容量转成运行路径。
- **主要问题：** 官杀传统语义极易被扩写为职位、道德、责任心和领导力；D6 不能仅凭约束存在自动增加。
- **派生层修正：** 只允许 `constraint_processing = single_clear_and_integrated` 修饰。D6 仅在另一个独立恢复/负荷家族支持时引用。
- **互斥/去重：** 与 020 对单清/混杂状态互斥；与 018 若复用同一官杀路径，受依赖簇上限约束。
- **反例：** 官杀虚浮、过重无制、两类并行无主次、或只产生压力而不能转成行动框架。
- **可否认行为候选：** 面对明确规则时，是否倾向先把职责、边界和完成条件整理清楚，再开始行动。
- **禁用推断：** 守法、品德高、服从、体制内、职位高、领导力、可靠人格。
- **审查状态：** `eligible_modifier`。

### MC-R-020｜官杀混杂且无解

- **原始候选作用：** D1 外部校准冲突、D6 压力波动；锚点 3。
- **可保留结构假设：** 两套有效约束同时作用、主次未定且无已验证解决路径时，可能形成标准冲突候选。
- **主要问题：** 官杀同现不等于混杂；“无解”是全局否定命题，必须与 038 的解决机制、食制、印化、合留和从一方形成完整白名单。
- **派生层修正：** 只在 `mixed_constraint_unresolved` 全部条件通过后作为 D1 反向候选；D6 波动仍需独立负荷/恢复证据。
- **互斥/依赖：** 与 019 互斥；与 038 强互斥。038 尚未审查，因此 020 暂不进入 B01/B06 槽。
- **反例：** 一方虚浮、主次清楚、有效食制/印化/合留存在，或两套标准作用于不同情境且并不冲突。
- **可否认行为候选：** 暂不进入报告；未来必须具体到“同时收到不兼容标准时是否持续自我审查或难以排序”。
- **禁用推断：** 婚恋混乱、克夫、低贱、人格矛盾、命局不清、灾祸。
- **审查状态：** `pending_definition`。

## 4. 跨规则结论

### 4.1 吸收与表达没有被合成一个维度

- 011 只描述输入偏置修饰；
- 012 描述输入到输出的连续路由；
- 014 描述输出通道存在；
- 015 描述显隐；
- 016 描述负荷。

它们分别作用于不同状态轴，但共享 `CL-INPUT-OUTPUT` 时不能被重复累计为多个独立人格证据。

### 4.2 D1 不由“比劫多/官杀多”直接决定

- 017 的内部参照仍被全局缺失判断阻塞；
- 018 是可谈判边界的来源待核验候选；
- 019 只修饰约束整合；
- 020 的多重标准冲突仍被解决机制审查阻塞。

### 4.3 本批首次形成三个“结构已接近可用”的锚点候选

```text
MC-R-012 → D2/D4 输入—输出路由候选
MC-R-014 → D4 输出通道候选
MC-R-018 → D1 可谈判边界候选
```

它们仍为 `pending_source`，不占据冻结槽，不进入真人报告，也不代表现代机制成立。
