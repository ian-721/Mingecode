## 3. 逐条审查

### MC-R-031｜六合形成有效协同

- **原始候选作用：** D1 边界趋协商；结构协同支持 2。
- **可保留结构事实：** 两个有效对象之间存在稳定的引化、转向或原作用重新分配。
- **主要问题：** “六合”不等于合作，“化神出现”不等于真正转化；不同流派对得时、得势、引化和争合判据不一致。
- **派生层修正：** 只记录 `combine_relation_state = redirected_or_stable_interface`，不增加 D1。
- **互斥/去重：** 与 032 对同一对象互斥；与 038、024 等更具体解决链同对象时，采用更具体机制，031不再计。
- **反例：** 关系名义存在但一端无效；化神无承接；争合或强冲破合；时间候选改变关系。
- **可否认行为候选：** 不释放。传统关系状态不能直接提出“会协商/会整合”。
- **禁用推断：** 合作型、善解人意、关系高手、婚缘好、逢合必吉。
- **审查状态：** `sensitivity_only`。

### MC-R-032｜合而不化形成牵绊

- **原始候选作用：** D1 受关系牵引、D5 收口延迟；支持 2。
- **可保留结构事实：** 两端有效且关系占用成立，但没有稳定转化，双方原功能受到牵制。
- **主要问题：** 现代“合绊”解释差异大；从结构状态直接推到犹豫、关系依赖或难收口没有独立证据。
- **派生层修正：** 只记录 `combine_relation_state = binding_without_redirection`。
- **互斥/去重：** 与 031 互斥；若冲开、明确主次或连续链已经解释对象状态，则关闭032。
- **反例：** 有效引化完成；关系只名义存在；两端作用于不同对象；更具体资源/约束链已解决。
- **可否认行为候选：** 不释放。
- **禁用推断：** 优柔寡断、离不开关系、拖延、婚恋纠缠、关系必坏。
- **审查状态：** `sensitivity_only`。

### MC-R-033｜势均之冲产生激活

- **原始候选作用：** D3 探索启动或情境切换增加；支持 2。
- **可保留结构事实：** 两个有效、力量接近的对象相冲，双方均未被拔除，形成重组或切换候选。
- **主要问题：** “冲=动”不能直接翻译为探索、试验、迁移或行动力；势均判断易被主观化。
- **派生层修正：** 只记录 `clash_relation_state = comparable_activation`，删除自动 D3。
- **互斥/去重：** 与 034 同对象互斥；若另有更具体的输出、资源或约束冲突规则，以具体规则为主。
- **反例：** 一端虚弱；冲被合解；双方不在同一对象；时支边界改变强弱关系。
- **可否认行为候选：** 不释放；未来如保留，只能在独立行为证据下作为情境修饰。
- **禁用推断：** 爱变化、爱旅行、行动力强、敢探索、人生动荡。
- **审查状态：** `sensitivity_only`。

### MC-R-034｜强弱悬殊之冲

- **原始候选作用：** 关键功能稳定性下降、D6 承载波动；锚点 3。
- **可保留结构事实：** 一端明显占优，弱端承担关键节点且没有独立救应，关键节点可能被覆盖。
- **主要问题：** 强弱分类仍依赖多项结构事实；“能迅速放弃旧结构”是未经支持的正向补偿。
- **派生层修正：** 只记录 `clash_relation_state = dominant_displacement`，不形成D6锚点。
- **互斥/去重：** 与 033 互斥；若弱端就是003的唯一关键根，采用003的单点容量脆弱叙事；与029/030同对象时取最具体原因。
- **反例：** 弱端有独立支持；冲被有效化解；强弱无法稳定判断；关键节点并非必要。
- **可否认行为候选：** 不释放。
- **禁用推断：** 脆弱人格、突然失败、灾祸、断裂命运、适应力强。
- **审查状态：** `sensitivity_only`。

### MC-R-035｜重复刑形成内部摩擦

- **原始候选作用：** D6 成本增加、D2 反复加工；细节 1。
- **可保留结构事实：** 重复刑关系与某个有效功能重叠。
- **主要问题：** 刑的传统解释和现代映射分歧大；“反复校验”“内耗”均可能是巴纳姆文本。
- **派生层修正：** 仅附录记录，不生成维度、原型、声明或正向补偿。
- **互斥/去重：** 若冲、合、直接制约或负荷规则已解释同一对象，不再使用035。
- **反例：** 仅一处弱刑；对象无效；功能有明确出口；时间候选不稳定。
- **可否认行为候选：** 无。
- **禁用推断：** 内耗、强迫、犯罪、疾病、灾祸、特别细致。
- **审查状态：** `sensitivity_only`；`core_eligibility = hard_excluded`。

### MC-R-036｜害作为隐性干扰候选

- **原始候选作用：** 情境细节；细节 1。
- **可保留结构事实：** 名义害关系涉及有效对象，且尚无更具体机制解释。
- **主要问题：** 解释增量几乎不可观察，极易成为任何不适的兜底标签。
- **派生层修正：** 仅附录保留“未解释关系标签”，不生成现代机制。
- **互斥/去重：** 任何更具体的冲、合、链断、竞争、负荷或接口规则均优先并关闭036。
- **反例：** 名义存在但无功能影响；对象有独立通道；其他规则已充分解释。
- **可否认行为候选：** 无。
- **禁用推断：** 隐性不匹配、直觉敏锐、被暗中消耗、关系有害、疾病灾祸。
- **审查状态：** `sensitivity_only`；`core_eligibility = hard_excluded`。

### MC-R-037｜透藏不一致形成公私差异

- **原始候选作用：** D2/D4 场景差异；支持 2。
- **可保留结构事实：** 一个公开有效功能与一个藏层有效功能并存，二者不是同一连续链。
- **主要问题：** 透藏不同不等于“双面人格”或明确公私差异；必须先由既有规则分别确认两端。
- **派生层修正：** 只作为 `CL-VISIBILITY-STATE` 组合修饰，不新增证据家族。
- **互斥/去重：** 公开端若命中009则不能称稳定；藏端若命中010则不释放；与004/005/014/015共享事实，核心计数不增加。
- **反例：** 一端虚浮；两端其实构成连续链；不同功能没有可区分情境；时间候选改变任一端。
- **可否认行为候选：** 只有在其他独立锚点成立时，才可测试“公开场景先做什么、私下准备阶段做什么”，并必须给反向条件。
- **禁用推断：** 外冷内热、两面、深藏不露、隐藏天才、表里不一。
- **审查状态：** `eligible_modifier`。

### MC-R-038｜官杀混杂经合留或制化解决

- **原始候选作用：** D1 外部标准可整合、D6 压力可承载；支持 2。
- **可保留结构事实：** 两种原本有效的约束在同一对象中，经有效合留、制化或稳定从属形成主次。
- **主要问题：** 名义合制和研究者事后挑主次不能算解决；现代“在复杂规范中找主轴”仍是项目假设。
- **派生层修正：** 定义为 `constraint_mix_state = mixed_resolved`，并建立解决白名单。
- **互斥/去重：** 与020同对象互斥；与019单一约束状态区分；若两端实际属于不同对象，只关闭020，不增加038正向证据。
- **反例：** 两端仍争夺同一对象；解决依赖岁运；作用位置或力量无效；合理时间候选改变主次。
- **可否认行为候选：** 暂不释放；来源门关闭后最多测试“多套明确标准冲突时，是否能稳定选出主标准并说明从属规则”。
- **禁用推断：** 成熟、高情商、会管理复杂组织、升职、道德稳定。
- **审查状态：** `pending_source`。

### MC-R-039｜容量强且泄制转化齐备

- **原始候选作用：** D6高承载，D4/D5至少一项有效；锚点 3。
- **可保留结构事实：** 容量有效，且至少一条输出/转化路由与一条边界/约束/完成路由有效、互不关闭。
- **主要问题：** 它是多个既有家族的综合状态，不是独立证据；“可持续做成事”是高声望、难否认的漂亮话。
- **派生层修正：** 定义为 `capacity_route_state = open_integrated_capacity`，只作全局开放门和007的反向状态。
- **互斥/去重：** 与007互斥；复用001/002/006、012/014/026、018/019/027等事实，绝不增加新家族。
- **反例：** 通道只是元素齐全；输出与约束互相关闭；负荷/竞争未解；任一关键路由时间不稳定。
- **可否认行为候选：** 暂不释放。未来只能作为多个具体声明的总门，不能单独写“可靠、能成事”。
- **禁用推断：** 高能力者、稳定成功、执行力强、别人都依赖你、长期可靠。
- **审查状态：** `pending_source`；`core_role = composite_gate_only`。

### MC-R-040｜从格严格候选

- **原始候选作用：** 高度环境适配；不设权重。
- **可保留结构事实：** 日主无稳定根助，单一方向纯而有势，无异质通道，所有合理时间候选一致。
- **主要问题：** 从格判定流派分歧大、极易扩大使用；从结构到“环境适配”的现代映射未验证。
- **派生层修正：** 保留为未来专家复核与多流派一致性研究对象；本轮不生成维度或报告。
- **互斥/去重：** 任一根气、印比支持、混杂方向或时间边界变化关闭；不得用从格覆盖普通容量和路由规则来追求“更准”。
- **反例：** 存在稳定异质功能；主导方向并不纯；不同合理候选盘改变结构。
- **可否认行为候选：** 无。
- **禁用推断：** 真从必贵、破格必败、必须顺从、适应力极强、没有自我。
- **审查状态：** `sensitivity_only`；`core_eligibility = hard_excluded`。
