# CRX-0.5｜六条 pending_definition 去留裁决

**状态：** Draft Decision / Not Human-Tested

## 1. 裁决目标

并非所有“尚未定义完”的规则都值得继续投入。CRX-0.5 按三个问题裁决：

1. 它是否提供现有规则无法替代的机制？
2. 即使定义完成，能否形成具体、可否认且不依赖职业/性别/声望的行为？
3. 它是否只是容量、负荷、竞争或全局缺失的敏感性标签？

## 2. 逐条裁决

### MC-R-008｜支持实际到达

**决定：继续定义；目标不是核心锚点，而是恢复/支持守门。**

保留原因：它能区分“名义有印比”与“支持路径真的到达日主”，不能完全由001/002/006替代。

必须补齐：

- 支持路径连续性；
- 中间节点被关闭的判据；
- 支持相对负荷的分类，而非精确分数；
- 与001/002/006家族上限；
- 时间候选稳定性。

完成后最高状态：`eligible_modifier` 或 `gate_only`。

### MC-R-013｜关键输出被直接过滤

**决定：继续定义；目标为D4反向/过滤机制。**

保留原因：它能区分“没有输出”与“存在关键输出但被有效内部过滤”，对报告可否认性有真实增量。

必须补齐：

- 关键输出扫描；
- 替代输出白名单；
- 直接作用的位置/力量分类；
- 偏印必要扶身排除；
- 财制印与其他救应；
- 与011/012互斥回归。

完成后最高状态：`reverse_candidate`，不提供正向核心证据。

### MC-R-016｜输出负荷超过承载

**决定：降级为`sensitivity_only`，并并入统一容量负荷协议。**

原因：它与029共享容量、恢复和持续性事实；即使定义完成也只说明负荷来源，不形成独立人格家族。

允许用途：指出某条已成立输出路由可能伴随恢复风险；不生成“高产”“脉冲型”“容易耗尽”等人格结论。

### MC-R-017｜内部参照且外部约束弱

**决定：降级为`sensitivity_only`，取消D1锚点资格。**

原因：核心条件依赖证明“所有有效外部约束都缺失”，属于全局否定命题；同时比劫根气与容量背景高度重复，现代“自主、拒绝控制”推论过强。

D1若继续保留，应由018及020/038这类双端或对象特定状态支持，而不是由“约束缺席”定义整个人格。

### MC-R-029｜资源负荷超过容量

**决定：降级为`sensitivity_only`，与016组成统一负荷来源子型。**

原因：对象计数、持续期、恢复不足和从财排除均难以成为稳定核心规则；现代“机会太多/过度承诺”行为不能从结构直接推出。

允许用途：当026/027等资源路由已成立时，作为不释放过度正向文案的容量守门。

### MC-R-030｜关键资源直接竞争

**决定：降级为`sensitivity_only`，取消D1/D5反向槽资格。**

原因：对象竞争的结构合同虽可继续研究，但从比劫争财推到所有权、合作分配、公平感或边界行为的认识论跳跃过大；现实分配机制属于图外信息。

允许用途：关闭同对象025/026/027的正向释放，进入敏感性附录；不生成“好胜、资源敏感、边界强”等用户声明。

## 3. 统一负荷协议候选

016与029以后不再被当作两个独立规则家族，而是：

```text
LOAD-0 unknown
LOAD-1 route_present_and_recoverable
LOAD-2 output_source_overload_candidate   # 016
LOAD-3 resource_source_overload_candidate # 029
LOAD-4 mixed_or_unresolved
```

同一容量事实只能取一个最具体负荷来源；所有负荷状态只作守门，不增加正向证据。
