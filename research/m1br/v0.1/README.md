## 目标

重新建立一个适合轻量工具的研究模型：

```text
出生信息
→ 命盘结构签名候选
→ 默认三道自适应校准题
→ 命盘底色 / 现实路线 / 二者关系
→ 结果结构
```

用户侧仍只有两步：填写出生信息、回答三题。第四题只用于并列或冲突。

## 本轮边界

本轮只做：

1. 四个整体结构签名合同；
2. 十二个校准题槽；
3. 自适应选题与结果裁决逻辑；
4. 结果数据结构；
5. 语言风险门；
6. 8—12人探索材料计划。

本轮不做：

- 正式用户文案；
- 题目最终措辞；
- H5、排盘库、数据库、API或部署；
- 真人招募或测试；
- 完整视觉系统；
- 准确率、科学人格或已验证规则宣传。

## 方法承接

Draft PR #3 保留纯八字人格规则路线的研究记录。M1-BR 继承其中有效的治理成果：

- 排盘事实、传统解释、现代假设和用户表达分层；
- 相关证据不得重复计数；
- 显隐、负荷、时间和冲突只作守门；
- 报告必须可否认、等质并接受反巴纳姆检查；
- 不因原型名称、视觉或传播力保留无依据结构。

M1-BR 不继承以下产品约束：

- 六维必须成立；
- 八原型必须保留；
- 二十四槽必须填满；
- 八字单独给出最终人格。
