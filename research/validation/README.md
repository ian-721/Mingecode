# 验证研究

**状态：候选研究方案 / Proposed / 待验证**

M1 采用四选一纯内容盲测验证候选人格的区分度，并用基础命名测试验证公开产品名候选。任何测试开始前必须预先记录样本、材料控制、通过标准和停止条件。

## 四选一盲测

- 一份本人规则报告加三份真实错配报告；
- 四份内容长度、语气和正负比例受控；
- 隐藏原型名、插画和传统术语；
- 记录完整排序、理由、最像与最不像段落；
- 记录保存、分享和邀请第二人的意愿；
- 不得把“选中本人”单独包装成科学准确率。

模板：[BLIND_TEST_TEMPLATE.md](BLIND_TEST_TEMPLATE.md)

## 命名测试

测试理解、好感、记忆、口头传播、分享意愿和误读风险，不诱导用户选择八字没一撇这一**候选 / Proposed / 待命名测试**的公开产品名。

模板：[NAMING_TEST_TEMPLATE.md](NAMING_TEST_TEMPLATE.md)

所有结果必须来自真实测试；未执行时只能标记“待核验”，不得填写推测数据。
