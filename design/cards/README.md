# 卡片文件治理

**状态：候选治理 / Proposed / 待验证**

当前只定义文件治理和未来输出要求，不创建正式卡片或完整卡片系统。

未来候选卡片必须验证：

- **识别度**：遮住名称后仍能感到候选之间的气质差异；
- **系列感**：属于统一系统，不像不同素材库拼接；
- **可读性**：移动端层级清楚；
- **分享欲**：不像传统算命广告，用户愿意保存或分享；
- **可扩展性**：新增候选时可沿用网格和视觉逻辑；
- **生产可行性**：字体、图像与组件可在目标媒介稳定复用。

用户应在手机屏幕三秒内看到：

1. 我是什么；
2. 哪句话像我；
3. 为什么值得分享。

只有候选原型通过纯内容盲测后，才可评估正式卡片制作。
