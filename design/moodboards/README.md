# 轻量 Moodboard 探索

**状态：候选 / Proposed / 待验证**

首轮仅探索三套轻量方向，不在本阶段生成正式 Moodboard 图片：

1. **现代东方编辑风**：留白、汉字、现代排版与克制的传统纹理；
2. **人格收藏卡风**：独立象征物、编号、卡面与系列收藏感；
3. **轻角色插画风**：现代角色或轻量形象，强调亲切与娱乐性。

每套方向只用于验证气质、理解和分享意愿。不得制作正式 Logo、完整品牌系统、高保真 UI 或全部人格卡；不得以精美程度替代纯内容盲测。

八字没一撇仍是**候选 / Proposed / 待命名测试**的公开产品名；可探索“一撇未完成”的概念，但不能在命名测试前将其固化为终局视觉。
