# 设计区

**状态：候选探索 / Proposed / 待验证**

延雨婷是视觉与体验负责人。当前处于轻量视觉探索阶段，只允许为两个候选原型准备视觉简报和低成本样稿。

## 阶段边界

- 人格纯内容盲测必须早于完整卡片制作；
- 当前不得建立全部人格卡系统；
- 当前不得制作正式 Logo 终稿；
- 当前不得制作完整高保真产品 UI；
- 不得因为某个候选原型更好画就保留它；
- 公开产品名仍待命名测试，视觉投入不得反向冻结名称。

## 推荐视觉原则

- 东方文化底色；
- 现代人格卡表达；
- 轻松、年轻、可分享；
- 手机上快速可读，兼顾系列感与生产可行性。

## 避免方向

- 传统算命广告感；
- 满屏金色、八卦、铜钱、龙纹；
- “大师批命”式权威感；
- 千篇一律的 AI 国潮仙人；
- 以视觉夸张掩盖人格内容无区分度。
